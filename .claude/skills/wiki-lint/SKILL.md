# wiki を保守する

規約は [LLM wiki の仕組み](../../docs/llm-wiki.md)。始める前と終えるときは「操作の共通の手順」に従う。直してよいのは `wiki/` だけ（[所有の区分](../../docs/llm-wiki.md#所有の区分)）。

## 1. 機械的な検査

```sh
node .claude/scripts/wiki-lint.mjs
node .claude/scripts/usage-report.mjs   # 参照されていないページ、更新されていないページ
```

- `wiki/` のエラーは直す
- `sources/` のエラーは直さずにユーザーに伝える（元資料は変更しない。直す許可が出たら、通常のコミットで直す）
- 警告（人のノート）は直さずに、一覧をユーザーに伝える

## 2. 内容の点検

ページが多いときは、最近更新されたページと、長く更新されていないページから見る。

| 見るもの | 直し方 |
|---|---|
| ページ間の矛盾 | 元資料を確かめ、両方を出典付きで書くか、新しい方に揃えて古い方を「以前は〜とされていた」と残す |
| 新しい元資料で古くなった記述 | 更新して `updated` を変える |
| 孤立したページ（どこからも参照されない） | 関連するページからリンクを張る。価値がなければ統合する |
| 重複したページ | 1 つに統合し、リンクを書き換える。人のノートから参照されている旧ページは消さず、新ページへのリンクだけを残す |
| 何度も出てくるのにページがない概念 | ページを作る |
| 張られていない相互リンク | 張る |
| 根拠のない記述 | 出典を探して付けるか、「推測」と明記する |

ページの内容を大きく消すとき（特に、人が手で書き足した部分）は、log に理由を書く。

## 3. 足りない情報を提案する

点検で分かった、wiki に足りない情報（調べるとよい問い、探すとよい元資料）をユーザーに提案する。

## 4. 記録して終える

`wiki/log.md` に `lint` として記録し（直したこと、ユーザーに伝えた警告、提案）、「操作の共通の手順」の「終えるとき」に従う。
