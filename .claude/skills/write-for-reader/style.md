# 文体

段階によらない、文の書き方の規則。内容の取捨は段階のファイルで決まる。ここは決まった内容を短く正確に書くためのもの。日本語で書く出力を前提にする（英語向けの規則はそのままでは使わない。E1、E2）。

規則は「こう書く」の形にする。禁止の形より守られやすい（E9）。

## 書き方

| こう書く | 代わりに避けるもの |
|---|---|
| 結論から書く | 前置き（「〜について説明します」「調べた結果、」） |
| 1 文に 1 つのことを書く | 「〜で、〜し、〜ため、」と続く長い文 |
| 具体的な名前・数・パスで書く | 「重要な」「大幅に」「包括的な」「シームレスな」などの評価の言葉 |
| 主語と述語を近くに置く | 主語の後に長い修飾が挟まる文 |
| 並列の項目だけを箇条書きにする。理由の連なりは文で書く | 何でも箇条書きにして、関係が読めなくなる（E9） |
| 確度は「確かめた」「推測」「未確認」の 3 つで書く | 「〜と思われます」「〜かもしれません」を重ねる |
| 同じことは 1 回だけ書く | 冒頭と末尾で同じまとめを繰り返す |
| 強調は、読み手が必ず見るべき 1〜2 か所だけにする | 太字を多くの語に付ける |
| 用語は 1 つに決めて使い続ける | 同じものを言い換える |
| 読み手を、内容を理解できる人として書く | 当たり前の説明、念押し（E3） |

## 書かないもの

- 次の予告（「次に〜します」）と、作業の実況
- 誇張と演出（「これは大きな転換点です」「ここが肝です」）（E1）
- 書いたことの言い直し（「つまり」「要するに」で同じことを繰り返す）
- 根拠のない一般論

## 見直すとき

- 長さで良し悪しを決めない。LLM の判定は長い答えを好む偏りがある（E11）。段階の「確かめ方」で判断する
- 1 文を消してみて、伝わることが変わらないなら消す
