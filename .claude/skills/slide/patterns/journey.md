# journey: 体験の旅

利用者の段階ごとの行動と、気持ちの上下を見せる。

## 使う場面

- どの段階で困っているかを、利用者の目線で示すとき

## 使わない場面

- 気持ちの記録がなく、手順だけを見せる（[process](process.md)）

## ひな形

```html
<section data-pattern="journey">
  <h2>いちばん不満が大きいのは、返事を待つ間</h2>
  <ol class="journey">
    <li style="--v:60"><h3>送る</h3><p>フォームに書く</p></li>
    <li class="low" style="--v:15"><h3>待つ</h3><p>4 時間返事がない</p></li>
    <li style="--v:50"><h3>やりとり</h3><p>担当と話す</p></li>
    <li style="--v:80"><h3>解決</h3><p>手続きが終わる</p></li>
  </ol>
</section>
```

## 書くときの指示

- `ol.journey` の `li` が段階。`<h3>`（段階）と 1 行の行動。気持ちは `style="--v:0〜100"`（高いほど良い）
- いちばん低い段階に `low`
- 6 段階まで

## よくある失敗

- 気持ちの値に根拠がない（聞き取りや調査の出典を `.source` に書く）

## 根拠

パターンそのものの実験の根拠はない。[共通の規約](../conventions.md) の配置の規則に従う形にした。C6、C9。
