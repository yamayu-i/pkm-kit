# cycle: 循環

回り続ける 4 つの段階を見せる。

## 使う場面

- 改善の回し方、繰り返す運用

## 使わない場面

- 一度きりの流れ（[process](process.md)）
- 段階が 4 つでないとき（[process](process.md) に「最初に戻る」と書く）

## ひな形

```html
<section data-pattern="cycle">
  <h2>規則は、月 1 回の見直しで育てる</h2>
  <ol class="cycle">
    <li><h3>振り分ける</h3><p>規則で担当を決める</p></li>
    <li><h3>記録する</h3><p>人が直した件を残す</p></li>
    <li><h3>見直す</h3><p>直しの多い規則を探す</p></li>
    <li><h3>直す</h3><p>規則を足す・変える</p></li>
  </ol>
</section>
```

## 書くときの指示

- 4 つを、左上から時計回りに置く（1 → 2 → 3 → 4 → 1）
- どこから始まるかを話で言う

## よくある失敗

- 循環しないもの（最後が最初につながらない）を輪にする
