# summary: まとめ

持ち帰ってほしいことを最後に言い直す。

## 使う場面

- 話の終わり（[next-steps](next-steps.md) の前）

## 使わない場面

- 新しい話を足したくなったとき（本編に戻す）

## ひな形

```html
<section data-pattern="summary">
  <h2>自動振り分けで、初回応答は 1 時間に縮められる</h2>
  <ul class="takeaways">
    <li>待ちの 7 割は、担当を決めるまでに生じている</li>
    <li>試験導入の 2 チームでは、4 時間が 50 分になった</li>
    <li>全チームへの展開は、設定の追加だけで済む</li>
  </ul>
</section>
```

## 書くときの指示

- 見出しは話全体の結論。表紙の `<h1>` と同じことを言ってよい
- 項目は本編の章の結論をそのまま並べる（4 つまで）

## よくある失敗

- 「ご清聴ありがとうございました」だけにする
- 本編にない話を足す

## 根拠

[共通の規約](../conventions.md) の C1、C4、C12。
