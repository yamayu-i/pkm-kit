# cover-image: 写真の表紙

写真を全面に敷いて、何の話かを印象とともに示す。

## 使う場面

- 現場・製品・場所の写真が、話の主題をそのまま表すとき

## 使わない場面

- 主題を表す写真がないとき（[cover](cover.md)。飾りの写真を置かない）
- 端が切れて困る写真（全面に敷くので、枠に合わせて端が切れる）

## ひな形

```html
<section data-pattern="cover-image">
  <h1>問い合わせの初回応答を、4 時間から 1 時間に縮める</h1>
  <p class="lead">受付の自動振り分けを、来月から全チームに広げたい</p>
  <p class="meta">サポート企画 · 2026-11-11</p>
  <figure class="bleed"><img src="support-floor.jpg" alt="サポートの執務室。担当者が画面の問い合わせの一覧を見ている"></figure>
</section>
```

## 書くときの指示

- `<h1>`・`.lead`・`.meta` を先に書き、`<figure class="bleed">` を最後に置く（見出しのまとまりは写真の上の白い面に出る）
- 写真は横長（16:9 に近いもの）を選ぶ。全面に敷くので、上下か左右の端が切れる
- `alt` に何が写っているかを書く

## よくある失敗

- 主題と関係のない雰囲気の写真を使う（C1）
- 大事なものが写真の端にある（切れる）

## 根拠

パターンそのものの実験の根拠はない。[共通の規約](../conventions.md) の配置の規則に従う形にした。C1（飾りの写真を載せない）。
