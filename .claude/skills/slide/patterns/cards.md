# cards: 並ぶ要素

同じ重さの 2〜4 個の要素（柱、理由、特長）を並べる。

## 使う場面

- 理由が 3 つある、柱が 3 本ある、のように並ぶもの

## 使わない場面

- 順番があるとき（[process](process.md)）
- 5 つ以上あるとき（まとめ直すか、2 枚に分ける）

## ひな形

```html
<section data-pattern="cards">
  <h2>自動振り分けは、3 つの情報だけで担当を決める</h2>
  <div class="cols">
    <div class="card" data-step><h3>問い合わせの種類</h3><p>フォームで選んだ分類</p></div>
    <div class="card" data-step><h3>契約のプラン</h3><p>顧客の情報から引く</p></div>
    <div class="card" data-step><h3>担当の空き</h3><p>今持っている件数</p></div>
  </div>
</section>
```

## 書くときの指示

- カードは 4 つまで。`<h3>` と 1〜2 行の説明だけにする（5〜6 個書くと 3 列の 2 段になるが、まとめ直せないかを先に考える）
- `<h3>` は短い名詞にする。長いカタカナ語や英単語は、カードの幅に合わせて文字が小さくなる
- 順に説明するなら `data-step` を付ける
- 色は付けないか、1 つだけ目立たせる

## よくある失敗

- カードごとに色を変える（色の違いに意味がない）
- カードに箇条書きを詰める

## 根拠

[共通の規約](../conventions.md) の C4、C6、C10。
