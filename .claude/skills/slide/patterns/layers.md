# layers: 層

上下に重なる層（構成、抽象度）を見せる。

## 使う場面

- システムの層、役割の階層、抽象から具体

## 使わない場面

- 順に進む流れ（[process](process.md)）
- 全体を部分に分けるとき（[tree](tree.md)）

## ひな形

```html
<section data-pattern="layers">
  <h2>振り分けは、受付と担当の間の 1 層として入る</h2>
  <ol class="layers">
    <li><h3>受付</h3><p>フォーム・メール・電話の記録</p></li>
    <li class="primary"><h3>振り分け</h3><p>種類・プラン・空きから担当を決める</p></li>
    <li><h3>担当</h3><p>各チームの担当者が返す</p></li>
  </ol>
</section>
```

## 書くときの指示

- 上から下へ、4 層まで
- 話題にしている層 1 つだけに `primary`

## よくある失敗

- 層の間の関係（上が下を使う、など）を話で補わない

## 根拠

[共通の規約](../conventions.md) の C4、C6。
