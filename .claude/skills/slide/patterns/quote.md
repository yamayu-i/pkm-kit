# quote: 引用

誰かの言葉で裏付ける。

## 使う場面

- 利用者の声、現場の言葉、識者の言葉が根拠になるとき

## 使わない場面

- 長い文章（要点を自分の言葉にして [statement](statement.md)）

## ひな形

```html
<section data-pattern="quote">
  <h2>担当者も、朝の振り分けを待つ時間を負担に感じている</h2>
  <blockquote>
    <p>朝の会議が終わるまで、<mark>誰も手を付けられない</mark>問い合わせが溜まっていく。</p>
    <cite>請求チームの担当者（10 月の聞き取り）</cite>
  </blockquote>
</section>
```

## 書くときの指示

- 見出しで、その言葉から何が言えるかを言う
- 引用は 3 行まで。見てほしい語句に `<mark>` を 1 か所
- `<cite>` に、誰の・いつの言葉かを書く

## よくある失敗

- 有名な格言を飾りとして置く

## 根拠

[共通の規約](../conventions.md) の C1、C6。
