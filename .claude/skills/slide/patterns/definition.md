# definition: 定義

言葉の意味を決め、例と例でないものを示す。

## 使う場面

- この話で使う言葉の意味を、先にそろえたいとき

## 使わない場面

- 聞き手が全員知っている言葉

## ひな形

```html
<section data-pattern="definition">
  <h2>「初回応答」は、人が書いた最初の返事を指す</h2>
  <dl>
    <dt>初回応答</dt>
    <dd>受付から、担当者が内容に答える最初の返事までの時間</dd>
  </dl>
  <div class="cols">
    <div class="card green"><p class="chip">含む</p><p>担当者からの「確認して折り返します」</p></div>
    <div class="card gray"><p class="chip">含まない</p><p>受付の自動返信メール</p></div>
  </div>
</section>
```

## 書くときの指示

- 見出しで定義を言い切る
- 例と、例でないものを 1 つずつ添える

## よくある失敗

- 辞書の定義を写し、この話での意味になっていない
