# section: 区切り

話が次のまとまりに移ることを知らせる。

## 使う場面

- 章の始まり

## 使わない場面

- 章が 2〜3 枚しかないとき（区切りの方が目立ってしまう）

## ひな形

```html
<section data-pattern="section">
  <p class="kicker">2</p>
  <h2>時間の 7 割は、担当を決めるまでの待ち</h2>
  <p class="lead">問い合わせ 1,200 件の記録から分かったこと</p>
</section>
```

## 書くときの指示

- `.kicker` は章の番号
- `<h2>` は章の結論を文で書く

## よくある失敗

- 章の名前（「原因分析」）だけを書く

## 根拠

[共通の規約](../conventions.md) の C2、C12。
