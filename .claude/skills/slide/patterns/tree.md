# tree: 木

全体を部分に分ける（内訳、組織、論点の分解）。

## 使う場面

- 論点の分解、内訳、組織

## 使わない場面

- 3 段を超える深さ（枝ごとに別のスライドにする）

## ひな形

```html
<section data-pattern="tree">
  <h2>初回応答の時間は、待ちと作業の 2 つに分けられる</h2>
  <ul class="tree">
    <li><span>初回応答までの 4 時間</span>
      <ul>
        <li><span>担当が決まるまでの待ち</span>
          <ul><li><span>朝の会議を待つ</span></li><li><span>会議での割り当て</span></li></ul>
        </li>
        <li><span>担当の作業</span>
          <ul><li><span>内容を読む</span></li><li><span>返事を書く</span></li></ul>
        </li>
      </ul>
    </li>
  </ul>
</section>
```

## 書くときの指示

- 根は 1 つ。1 段目は 2〜4 つ、2 段目はそれぞれ 4 つまで
- 文字は `<span>` に入れる
- 漏れと重なりがない分け方にする

## よくある失敗

- 枝の数が段ごとにばらばらで、何で分けたのかが分からない
