# 規約の根拠

[共通の規約](conventions.md) の根拠。2026-11-11 に、一次資料の本文を開いて確かめた結果による（[ADR-0117](../../../.kit/src/docs/adr/0117-slides.md)）。

## 採る基準

規則の根拠にするのは、次の 2 つを両方満たすものだけ。

- **確かめ方が「本文を読んだ」**: 論文・公式の文書の本文を開き、該当の数値や文を確かめた。要旨だけ・二次資料・未確認のものは採らない
- **確度が高か中**: 高は、本文で数値と条件を確かめ、無作為化実験か公式の仕様であるもの。中は、本文は確かめたが設計に弱点があるもの

採らなかったものは、下の「採らなかったもの」に理由と一緒に残す。後で本文を確かめられたら、ここに足してから規約に使う（[保守](maintaining.md)）。

## 採らなかったもの

本文を確かめられなかったか、確度が低いので、規則の根拠にしていない。広く言われているものも含む。

| もの | 採らない理由 |
|---|---|
| Mayer のマルチメディア学習の原則（余計なものを除く、印を付ける、話す文を画面に並べない、説明は図の近くに、区切って出す、など）と効果量 | 第 3 版の本体を開けず、著者の別の章で確かめた（二次資料）。効果量は版によって大きく違う（話す文を並べない原則は 0.10 と 0.72〜0.87）。「区切って出す」の定義は学習者が進める場合で、話し手が進める場合は定義の外 |
| Kroodsma & Byers 2000（文字はスライドの高さの 1/25 以上が好まれる） | 要旨と断片だけ。好まれた比の具体値と手続きは未確認 |
| 視距離から文字の高さを決める式（ANSI/INFOCOMM V202.01。要素の高さ ≥ 視距離 ÷ 200） | 規格の本文は未確認（団体の説明ページの抜粋）。「要素」が大文字の高さか小文字の高さかも未確認 |
| Cowan 2001（短期記憶は約 4 チャンク）とその後の議論 | 要旨だけ。その後、固定の個数を否定する見方や 6.4 という推定がある。スライドは見え続けるので、記憶の上限をそのまま当てはめる根拠にならない（E11 は Kosslyn の規則として採った） |
| Cleveland & McGill 1984、Heer & Bostock 2010（量は位置で比べるのが最も正確） | 原文は未確認（追試の著者の要約と断片） |

| Minto のピラミッド原則、SCQA、action title | 一次資料は未確認。効果を確かめた研究も見つからない（実務の慣行）。最も近い根拠は E6 |
