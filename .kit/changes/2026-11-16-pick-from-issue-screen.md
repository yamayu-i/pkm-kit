## 変更の要約

- **issue 画面とサブイシューの行から、今日のボードに載せられるようにした**（Pick を Today の画面で選び直さなくてよい）
  - issue 画面: status の行に「Add to today's board」を足した（active のときだけ）。押すと今日のボードに載り、「On today's board」になる。もう一度押すと外す
  - サブイシュー: issue 画面の一覧の行と、本文の一覧（Live Preview・リーディング）の行に、同じ働きのアイコンを足した（終わっていないサブだけ）
  - どちらも日付は書かない（ADR-0152）。載せたものは Today の Pick の候補から消える
- 子への影響: 移行はない（データの形は変わらない）。子だけのスキルや `local/CLAUDE.md` に変える点はない
