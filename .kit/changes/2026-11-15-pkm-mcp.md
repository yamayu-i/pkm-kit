## 変更の要約

- **移行 0156-pkm-mcp**: Vault ルートの `.mcp.json` で、MCP サーバー（`.kit/bin/mcp.mjs`）を `pkm-task` などの名前で登録していたら `pkm` に改める。`.mcp.json` がなければ何もしない（新しい Vault はセットアップが置く）
- MCP サーバーの名前を `pkm` にし、ツールに群の接頭辞を付けた（ADR-0156 の段階 1）。`get_overview` → `task_get_overview` など。旧名も 1 版のあいだ呼べる（呼ぶと利用ログに旧名と記録される）
- 読み取りの群を足した: `note_search`（単純一致。全角・半角、大文字・小文字、カタカナ・ひらがなの違いを無視。title → aliases → tags → 本文の順）、`note_get`、`note_list`、`note_links`、`daily_get`、`daily_list_pending`、`wiki_get_index`、`wiki_recent_log`、`wiki_list_unprocessed_sources`、`check_vault`、`check_rename_candidates`。tmp/・template/・slide/・隠しパスは読まない
- `--toolset=task,note,...` で公開する群を選べる
- 起動中は索引をメモリに持ち、変わったファイルだけを読み直す（合成した 4,000 ファイルの Vault で 1 回 110〜150 ms → 13〜20 ms）
- 応答を小さくした: 整形しない、一覧は既定 20 件（`note_` などの群）、本文は既定 8,000 字、`task_get_overview` の `problems` と `stalled` は上位 5 件と件数（`problemCount`、`stalledCounts`）。エラーの先頭に種類（`[not_found]` など）を付けた
- 利用ログを `.claude/mcp-log/` に記録する（起動、呼び出し、AI からのフィードバック `meta_feedback`、MCP を通さないノートの読み書き）。ノートの本文は残さない。`.claude/settings.json` に PostToolUse のフック（`.kit/bin/mcp-hook.mjs`）を足した。`PKM_MCP_LOG=off` で止める。`usage-report.mjs` に「MCP の利用」の節を足し、harness-review が読む
- 子への影響: 移行 0156-pkm-mcp がある。`.mcp.json` 以外（`claude mcp add` で入れた設定、Cursor の設定）に登録しているなら、名前を `pkm` に直す（移行の README）。子だけのスキルや `local/CLAUDE.md` が旧名のツールを書いていれば直す。`.claude/mcp-log/` はコミットして同期する
