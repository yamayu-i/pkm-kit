## 変更の要約

- スライドを `slide/` に HTML で作れるようにした（ADR-0117）。Claude Code に「スライドを作って」と頼むと、聞き手と目的を聞き、見出しの表で話の筋を合意してから、`slide/<…>/<デッキ>/deck.html` を書いてビルドする（スキル slide）
- `slide/<デッキ>/index.html` をブラウザで開くと、全スライドの一覧、「Slide Show」（最大化、矢印キーでスライドと 1 つずつ出す部品を前後）、「Download as PDF」（印刷で「PDF に保存」。文字を選択・検索できる）、「Review」、「Presenter」（発表者ビュー）、発表者ノート、ライト / ダークが使える
- 「Review」で直したい部品を押してコメントを書き、「Copy review」でコピーして Claude Code に貼ると、そのとおりに直る。再読み込みすると、変わったスライドに「Updated」が付く
- CLI `node .kit/bin/slide.mjs`（`new` / `build` / `check` / `export` / `pdf` / `patterns`）を足した。`node .claude/scripts/verify.mjs` は、`slide/` があれば `index.html` が `deck.html` から作ったものと同じかを確かめる
- デザインは Material 3 を元にしたトークンの色と、34 のパターン（表紙、主張と根拠、比較、手順、グラフなど）。規約と根拠はスキルの `conventions.md` と `evidence.md`
- pkm-html に、スライドを OS のブラウザで開くコマンド「Open slide in browser」、ファイルのメニューの「Open in browser」、タブの右上のボタンを足した（Obsidian の中ではスクリプトが動かず、一覧だけが出るため）
- ノートの書式の規約に `slide/` を足した（添付はデッキのフォルダに置く。md を置かない）
- 子への影響: 移行なし（新しいフォルダ・CLI・スキルが増えるだけ）。スライドのコメントはブラウザに残り、端末間で同期しない。PC で確かめること: Chrome・Safari・Firefox での Slide Show と印刷、Obsidian の「Open in browser」。スマホで確かめること: Obsidian の中でスライドが一覧として読めること、「Open in browser」が使えるか
