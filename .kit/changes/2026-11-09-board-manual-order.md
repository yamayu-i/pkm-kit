## 変更の要約

- task board のグループ（サブグループと未分類を含む）の中で、カードを手で並べ替えられるようにした（ADR-0114）。PC はカードを別のカードの上に落とすとその前に入り、グループの空いているところに落とすと末尾に入る。モバイルはカードのメニュー（`···`）の「Move up」「Move down」
- 並べた順は翌日以降のボードにも引き継ぐ。新しく載ったカード（自動で載る今日の予定を含む）はグループの末尾に出る
- 並びはボードの操作ログ（`board/<端末名>/YYYY-MM.jsonl`）の新しい操作 `order` に書く。issue のファイルは変わらない
- MCP の `get_board` は、グループの中を同じ順で返す（`byGroup` の `cards` が issue と routine を合わせた画面の順）
- 子への影響: 移行なし。すべての端末で同期を終えるまで、古い版の pkm-task は `order` の行を「操作が不正です」と報告する（ボードのほかの状態は壊れない）
