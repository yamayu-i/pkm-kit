# ユーザー体験定義書・仕様書を子 Vault で読む

- Issue: #42
- 設計: ハーネスの ADR-0042
- 移行: なし（上流が持つ生成物として merge で届く）

ファイル一覧の pkm-guide/user-experience.html を PKM HTML で開くと、場面・画面・用語から今の体験と仕様を参照できる。入力と制約、操作と保存、失敗時の戻し方、端末差、実装から描画した画面例を収録する。

共通の章立て・目次・全文変換・リンク・画像配置は CLI で生成する。上流で定義や UI を変えた際の再生成漏れは verify が検査する。子で生成し直す必要はない。Vault 外に共有するときは Export HTML to tmp/ を使う。

同じ pkm-guide/ のパスに子の独自ファイルがある場合は、退避して git の衝突を解決する。セットアップで子のファイルを上書きしない。
