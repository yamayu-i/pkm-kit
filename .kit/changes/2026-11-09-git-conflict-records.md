## 変更の要約

- PKM Git で、片方の端末が消し、もう片方が編集したファイルの衝突を記録するようになった（ADR-0103）。今までどおり編集側を残し、その記録を `.pkm-git/conflicts/<ID>.json` に作ってマージのコミットに入れる。記録は全端末に届き、再起動しても未解決の一覧と ` · ⚠ N` に出る
- 未解決の一覧で、記録の行に Keep（ファイルを残す）と Delete（ファイルを消す）が出る。押すと記録を消して同期し、ほかの端末からも消える。ファイルがもうない記録は自動で消える。読めない記録は Delete record で消せる（自動では消さない）
- 共通祖先が複数ある履歴（別のリモートとのやり取りや、履歴の書き換えの後）をマージするとき、祖先によって内容が違うファイルは、片方の変更を黙って戻さずに衝突として両方を残す。起きたことは同期の記録（Show sync log）に残る
- 子への影響: 移行はない。新しい隠しフォルダ `.pkm-git/` が、衝突が起きたときだけ Vault にでき、同期される。手で書き換えない。2 台で同じファイルを片方は消し片方は編集して同期し、一覧に記録の行が出ること、Keep か Delete で両方の端末から消えることを確かめる
