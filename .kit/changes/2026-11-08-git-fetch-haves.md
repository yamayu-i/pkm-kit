## 変更の要約

- PKM Git: 未 push のコミット（snapshot やマージ）があると、pull・push のたびにリモートの全履歴を取り直していたのを直した。前回取得したリモートの先端をサーバーに伝え、差分だけを取得する。履歴が長い Vault ほど、同期の通信量と時間が減る
- PKM Git: 開発者向けのコンソール（debug）に、clone・fetch・push のリクエスト数と送受信のバイト数を出す
- 子への影響: 移行なし。各端末で Obsidian を開き直す。スマホで pull と push が今までどおり動くこと、コンソールが見られる PC では fetch の received が小さいことを確かめる
