## 変更の要約

- サブを closed / canceled にすると、そのサブのブロックが issue の md の末尾へ移る（ADR-0181）。ヘッダー、ボード、Edit ダイアログ、本文のカード、タイマー、MCP / CLI のどこから変えても同じ。open に戻しても位置は動かさない
- issue の本文（Live Preview と Reading）で、終わったサブのカードと本文を隠すようにした。最後のサブの下の「Show N closed」を押すと出て、「Hide closed」で戻る。状態は保存しないので、ノートを開き直すと隠れる
- 子への影響: 移行 0181 が、すでに終わっているサブを各 issue の md の末尾へ集める（md の並びが変わる）。移行の後に、サブのある issue を開いて、終わったサブが末尾にあり、本文では「Show N closed」を押すまで隠れていること、サブを closed にすると末尾へ移ることを確かめる
