## 変更の要約

- ノートのコードブロックとインラインコードの面（Obsidian の `--code-background`）を、トークンの一段強い面（`surface-container-high`。ライト `#e8e7e2` / ダーク `#2b2b2b`）に固定した。これまでは Obsidian の既定のままで、本文の面とほぼ同じ色だった（ライトでは本文より明るかった）
- コードの面にも載る薄い文字（`--text-faint`。コードのコメントなど）を、ダークで `#8c8c8c` から `#949494` に上げた。コードの面の上で 4.5:1 を保つため
- 子への影響: 移行はない。スニペット `pkm-theme` の更新が merge で届く。各端末で Obsidian を開き直し、ライト / ダークの両方でコードの面が本文と見分けられることを確かめる
