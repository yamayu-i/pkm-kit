## 変更の要約

- **移行 0089-file-recovery**: `.obsidian/core-plugins.json` の `file-recovery` を `true` にする（コアプラグイン「ファイル回復」を有効にする）。上流が求める設定（`.kit/obsidian-required.json`）にも足した
- PKM Git が自動で同期するようになった（ADR-0089）。画面を表示している間は 5 分ごと、戻ってきたとき、起動したときに、取り込んでから送る。間隔は設定「自動の同期の間隔（分）」で変えられ、0 で止まる（手での同期はできる）
- Git のコミットは同期の区切りだけで作る。オフラインの間はコミットせず、つながったときに 1 つの snapshot にまとまる。保存のたびの細かな版は、ファイル回復が端末内に持つ
- 新しいコマンド: Sync now、Keep this version（名前を付けて今の版をコミットする。オフラインでも残る）、Show sync log
- Pull と Push のコマンドは、どちらも同期になる。Push は、リモートが先に進んでいてもモーダルで止めずに、取り込んでから送る
- リボンの Git: pull と Git: push のボタンが、Git: Sync の 1 つになった
- ステータスバーが、Git: Synced（共有済み）、Not synced（共有待ち）、Syncing…、Offline、Check connection、Sync failed を出す。未解決のコンフリクトの件数は ` · ⚠ N` で後ろに付く
- 取り込みの途中でアプリが終わっても、次の同期の始めに続きから直す。同期の間に Git の CLI がコミットしたら、そのコミットをブランチから外さない
- 同期の失敗と自動の回復は、端末ごとに `.git/pkm-git/log.jsonl` に残る（コミットにも同期にも入らない。最大 512 KiB）
- 子への影響: 移行 0089 がある（`vault-upgrade` で実行する）。更新すると各端末で自動の同期が始まる。止めたい端末は設定で 0 にする。スマホと PC で、ファイル回復が有効なこと（設定 → コアプラグイン）、起動して少し待つとステータスバーが Git: Synced になること、オフラインで書いてからつながると送られること、Keep this version と Show sync log が動くことを確かめる
