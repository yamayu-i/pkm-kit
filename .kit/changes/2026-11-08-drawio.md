## 変更の要約

- **移行 0064-drawio**: `.obsidian/community-plugins.json` に新しいプラグイン `pkm-drawio` を足す
- 新しいプラグイン pkm-drawio（ADR-0064）。図は `asset/<名前>.drawio.svg`（Draw.io の編集可能 SVG。描画と全ページの編集用 XML を 1 ファイルに持つ）に置き、`![説明](asset/<名前>.drawio.svg)` で参照する。表示は Obsidian の普通の画像の表示のまま
- 図の画像にマウスを載せる（タッチでは押す）と、右上に「コピー」「編集」が出る。コピーは PNG / SVG（編集用 XML なし）/ XML（全ページ）。編集は Obsidian の中で Draw.io（embed.diagrams.net。ネットワークが要る）を開き、保存すると図を書き換える。編集中にファイルが変わっていたら上書きせずに選ぶ
- コマンド「図を作る」「ノートの図を編集」「ノートの図をコピー」「このノートを tmp/ に書き出す（図を埋め込む）」。書き出しは、md / html の図の参照を、編集用 XML を除いた SVG の data URI に置き換えて `tmp/` に書く
- CLI `node .kit/bin/drawio.mjs`（`export` / `check` / `extract` / `strip`）。Claude Code が `tmp/` に共有用の md / html を作るときは `export` を通す（`.claude/docs/vault-conventions.md`）
- pkm-git: 両側で変わった `.drawio.svg` / `.drawio` を行単位でマージせず、リモート版と `<名前> (conflict <端末> <日時>).drawio.svg` を残す。衝突の版の名前は `.drawio.svg` の二重の拡張子を保つ。`.gitattributes` で PC の Git も同じく行単位でマージしない
- 子への影響: 移行 0064 がある（`vault-upgrade` で実行する）。各端末で Obsidian を開き直し、図を作る・編集して保存する・開き直して全ページが残っている・コピーを貼り付ける・tmp/ に書き出して図が見える、を確かめる（モバイルでは操作バーを押して出すこと、編集画面が開いて保存できること、クリップボードを特に確かめる）
