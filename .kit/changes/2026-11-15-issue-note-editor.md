# Issue とサブの Note 編集

- issue ヘッダーのサブ一覧で、タイトルを押すと編集ダイアログが開く
- 編集ダイアログの「Notes」を「Note」に変更。編集中の段落は Markdown ソース、ほかの段落はプレビューで表示する。プレビューを押すとその段落を編集できる。Save で保存、Cancel で破棄する
- 新規 Issue とサブの本文は `# Note` と空行に統一。以前の ToDo / Description / Note の初期テンプレートは使用しない。既存の本文には移行しない
- 子への影響: 移行なし。プラグインと MCP の成果物を更新。新規作成の本文、タイトルからの編集、Note 内での入力・改行・Undo・保存を確かめる
