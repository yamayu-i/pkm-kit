# ADR-0067: 行頭か空白の後の @ で、インラインテンプレートを行の中に挿入する

- 状態: 提案
- 日付: 2026-11-08

## 背景

- スニペット（ADR-0060）は行頭の `/` で、見出しなど行単位の断片を入れる。文の途中（「締め切りは 2026-11-20 まで」など）に短い値を入れる手段はない
- `{{prompt-date}}`（ADR-0065）で選んだ日付を、本文の途中にも入れたい
- 行の中で `/` を使うと、パスや日付の入力で毎回候補が開く（ADR-0060 で却下した案）

## 決定

### 1. 置き場所と書式

| 置き場所 | 持ち主 |
|---|---|
| `template/inline/*.md`（直下だけ） | その Vault（子） |
| `.kit/templates/inline/*.md`（直下だけ） | 上流の既定（プリセット） |

- 書式・重ね方・変数の展開はスニペットと同じ（frontmatter は `name` と `alias`。どちらも必須のケバブケース。同じファイル名ならその Vault のもの。`{{cursor}}`・`{{prompt-date}}` も同じ）
- 違いは 1 つだけ: 行の中に入れるので、**本文の終わりの改行（続けて並ぶものすべて）を削って**挿入する。途中の改行はそのまま
- スニペットとは別のフォルダにし、候補も混ぜない（`/` で `@` のもの、`@` で `/` のものは出ない）

### 2. いつ候補を出すか

- **行頭か、半角空白（U+0020）の直後で `@` を打った直後から**候補を出す。行頭なら前の空白は要らない
- 文字の直後（`foo@bar` のようなメールアドレス）、タブ・全角空白の直後では出さない
- 続く間と終わり方はスニペットと同じ（カーソルの前が `@` とケバブケースの文字だけで、同じ行にある間。空白を打つ、範囲の外に出る、Escape、候補を選ぶで終わる。終わった `@` には戻っても出ない）。加えて、`@` の前の空白を消したら終わる
- 判定はスニペットと同じ `StateField` の仕組みを、きっかけの文字と「始めてよい位置」の規則だけ変えて使う（`src/core/snippet.ts` の `nextTriggerSession`）

### 3. 検索と挿入

- スニペットと同じ（`name` か `alias` の前方一致、表示は `alias: name`、alias の順）
- 選ぶと、`@` から入力した文字列までを展開した本文に置き換える。`@` の前の空白は残す
- `{{prompt-date}}` があれば挿入の前にダイアログを開き、キャンセルなら挿入せず `@…` を残す（ADR-0065）

### 4. 上流の既定

`date`（`prompt-date`）を置く。日付のダイアログを開き、選んだ日付（`2026-11-20` / `2026-11-20 FRI`）を入れる。

```md
---
name: prompt-date
alias: date
---
{{prompt-date}}
```

## 理由

- `@` は Markdown の書式と重ならず、日本語の文の中でも打ちやすい。前を行頭か半角空白に限ると、メールアドレスや `@user` を文字の続きで書いたときに候補が開かない
- スニペットと書式・検索をそろえると、覚えることが増えない。フォルダを分けると、行単位のもの（見出し）と行の中のもの（値）を選び間違えない
- ファイルは改行で終わるのが普通なので、そのまま入れると行が割れる。終わりの改行を削れば、書く人が気にしなくてよい

## 却下した案

- **スニペットのフォルダに置き、frontmatter の項目（`inline: true` など）で分ける**: `/` と `@` の候補に同じ一覧を絞って出すことになり、項目を書き忘れると行頭にしか出ない。フォルダで分ける方が見て分かる
- **行の中のどこでも `@` で出す**: メールアドレスやメンションの入力で毎回開く
- **空白の種類を広げる（タブ・全角空白）**: 依頼は半角空白。日本語入力の全角 `＠` も含め、必要になったら足す
- **本文の改行をそのまま入れる**: 1 行のものでも行が割れ、すべてのファイルの終わりの改行を消す書き方を強いる

## 影響

- pkm-template: `src/core/snippet.ts` に `@` の規則と終わりの改行の削り方、`creator.ts` に `template/inline/` の読み込み、`SnippetSuggest` に種類（`/` / `@`）を持たせる。ビルド済み `main.js` も変わる
- `.kit/templates/inline/prompt-date.md` を足す（上流の既定。`.kit/**` に当たる）。子の `template/inline/` は子のもの
- 依存は増えない。子のものを書き換える移行は要らない。`.kit/changes/` に変更を書く
- モバイル（iOS / Android の入力方式で `@` を打ったとき）でも候補の出方を確かめる
