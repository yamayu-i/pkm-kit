# ADR-0181: 終わったサブを md の末尾へ送り、本文では押すまで隠す

- 状態: 承認（一部置換: 0197）
- 日付: 2026-11-16

## 背景

ADR-0142 で、ヘッダーの一覧から closed / canceled のサブを隠し（Show N closed で出す）、並べ替えは md のブロックの並びで行うと決めた。ヘッダーの並べ替えは md に反映される。

しかし終わったサブは md の途中に残り、本文（Live Preview / Reading。ADR-0161）には常にカードと本文が出る。ヘッダーと本文で見え方が違い、残っている作業の中に終わったものが混ざる。ADR-0142 は「closed を一覧の最後にまとめる」を、md の並び（作業の順）が見えなくなるとして却下した。

## 決定

### 並び

- サブの status が closed / canceled に変わったら、そのサブのブロックを md の末尾へ移す。末尾にすでにある終わったサブの後ろに置く（終わった順に並ぶ）
- open などに戻したときは動かさない。位置は戻した人が並べ替える
- 読めなかったブロックは動かさない。移すのは、status を変えたサブのブロック 1 つだけ
- この移動は、status を変える書き込みのすべて（ヘッダー、ボード、Edit ダイアログ、本文のカード、タイマーの Pick、MCP / CLI）で同じにする。コア（`updateSubIssueText`）に置いて共有する
- Live Preview のカードで status を変えたときは、エディタの文書の変更として「項目の書き換え」と「ブロックの移動」を 1 回の dispatch で行う（入力中の状態を失わない。ADR-0161）

### 本文の表示

- Live Preview と Reading で、終わったサブのカードと本文を隠す。最後のサブ（終わっていないもの）の下に「Show N closed」のテキストボタンを置き、押すと出す（「Hide closed」で戻す）。件数が 0 なら出さない
- 状態は保存しない。ノートを開き直すと隠れる（ADR-0142 のヘッダーと同じ）
- カーソルが終わったサブのブロックの中にある間は、生の md を見せる（ADR-0161 と同じ）
- 終わったサブはすべて末尾に並ぶので、隠す範囲は 1 つの連続した領域になる

### ヘッダー

- 一覧の並びは md の順のまま。終わったサブは末尾に集まるので、Show closed で出る位置は最後になる
- 既存の挙動（ドラッグと Move up / down が md を並べ替える）は変えない。出ている行の間だけを動かす

### 既存のサブ

- 移行で、子の Vault のすべての issue について、すでに closed / canceled のサブを md の末尾へ移す。順序は元の md の並びを保つ。DailyNote には触れない

## 理由

- 終わったサブを md の末尾に集めると、ヘッダーと本文で同じ並びと同じ隠し方になる。本文は連続した 1 領域を畳むだけで済み、描画も単純になる
- md の並びを正本にしたままなので、手で md を直す人にも並びが見える
- 動かす条件を「status が終わりに変わったとき」だけにすると、人が決めた並びを勝手に崩さない

## 却下した案

- **表示だけを下に並べる（md の並びは変えない）**: 本文の隠す範囲が飛び飛びになり、描画が複雑になる。md を直接読む人には終わったサブが途中に残る
- **open に戻したときも元の位置へ戻す**: 元の位置を覚える場所がない
- **ヘッダーの Show closed と本文のボタンを連動させる**: 状態の持ち場所が増え、保存しない方針（ADR-0142）と合わせにくい

## 影響

- ADR-0142「closed のサブ」の「md の並びの位置に出す」と、却下案「closed を一覧の最後にまとめる」を置き換える。ADR-0161 に本文の表示の追記が要る
- `.kit/migrations/0181-sub-done-to-bottom/` を付ける。子の Vault の issue の md が変わる
- 書き込みのコア、Live Preview の装飾、Reading の後処理、テスト、`main.js` のビルドが変わる
