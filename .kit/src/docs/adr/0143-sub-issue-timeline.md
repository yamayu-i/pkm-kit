# ADR-0143: サブイシューのガントチャート（Timeline）

- 状態: 承認
- 日付: 2026-11-15

## 背景

ADR-0135 で、サブイシューに期間（`start` / `end`）と依存（`depends_on`）を持たせた。PM には、それを時間の軸に並べて、重なりと順番、遅れを一目で見る画面が要る（#134 §3.4、#143）。画面の場所と操作は、この ADR で決めることにしていた。

## 決定

### 置き場所

- 親の issue 画面のカード「Sub-issues」（ADR-0142）の見出しの右に、表示の切り替え（`List` / `Timeline`）を置く。既定は List。切り替えは保存しない
- Timeline は、その親のサブだけを出す。issue をまたぐガントチャート（複数の親を並べる View）は作らない（必要になってから考える）
- 出すサブと並びは List と同じ（md の順。closed / canceled は「Show N closed」のときだけ）

### 図の形

- 左に題の列（狭いペインでは細くし、題は省略する）、右に日の列。日の列はカードの中で横にスクロールする（ページ全体は横にスクロールさせない）
- 目盛りを `Day` / `Week` で切り替える（既定は Day。保存しない）。週は日曜始まり（日曜〜土曜）
  - Day: 1 列が 1 日（幅 28px）。上に月と日。土日は面の色を変え、週の区切り（日曜の前）に細い線を引く
  - Week: 1 列が 1 週（1 日 12px、1 週 84px）。上に、その週の日曜の日付（`11/15`）。週の区切りに線を引く。棒・点・印・矢印は日単位の位置のまま出す
- 日の範囲: 出すサブの `start`・`end`・予定日・期限と今日を含む範囲に、前後 2 日を足す。Day は最低 14 日。Week は、始まりをその週の日曜、終わりをその週の土曜に広げ、最低 8 週
- 今日は primary の縦の線
- 棒: `start`〜`end`（両端の日を含む）。片方だけなら、その 1 日の棒。色は status の印の色。棒の中は空ける（題は左の列）
- 期間のないサブは棒を出さず、予定日を小さな点で、期限を印（soft deadline は amber、deadline は red の縦の短い線）で出す。何もなければ行に「No dates」
- `depends_on`: 依存先の棒の終わりから、そのサブの棒の始まりへの矢印。どちらかに棒がなければ出さない。依存先の `end` より前に始まる（lint の警告と同じ条件）ときは、矢印を error の色にする

### 操作

- 棒の真ん中をドラッグ: 期間を丸ごと日単位でずらす（Week の目盛りでも 1 日ずつ動く）。両端をドラッグ: `start` / `end` だけを変える（`start` は `end` を越えない）。マウスでも指でも動く（Pointer Events）
- 指を離したときに 1 回だけ保存する（ADR-0135 の検査を通す。#141 の `checkSubIssues`）。通らなければ通知に日本語の説明を出し、元に戻す
- 期間のない行の、日の列を押すと、その日を `start` と `end` にする（1 日の棒を作る）
- 題を押すと、Edit のダイアログ（ADR-0142）を開く
- キーボード: 棒にフォーカスでき、Enter で Edit のダイアログを開く。左右の矢印で 1 日ずらす（Shift + 矢印で `end` だけ）

### 文言

画面に常に出る文言（`List`、`Timeline`、`Day`、`Week`、`No dates`、ツールチップ、`aria-label`）は英語、通知とエラーの説明は日本語にする。

## 理由

- サブを見るのと同じカードの中で切り替えれば、別の画面に移らずに、並びと期間を両方見られる
- Week の目盛りで、数か月にわたる計画も 1 画面で見渡せる。週を日曜始まりにして、カレンダー（日付のストリップと月のカレンダー）と区切りをそろえる
- 日の幅を固定して横にスクロールすると、狭いペインでも 1 日の幅が潰れず、ドラッグで日を選べる
- 保存を指を離したときの 1 回にすると、md の書き込みと同期が増えない
- 期間のないサブにも点と印を出すと、期間を入れる前でも、予定と期限の分布が見える

## 却下した案

- **Mermaid の gantt でノートに書き出す**: 読むだけで、ドラッグで直せない。md の正本と二重になる
- **ヘッダーとは別の View にする**: 親の画面と行き来が要る。issue をまたぐ表示が要るとはまだ分かっていない
- **ペインの幅に合わせて 1 日の幅を変える**: 長い期間で 1 日が数 px になり、ドラッグで日を選べない
- **ドラッグ中も保存する**: 書き込みと同期が増え、端末間でぶつかりやすい

## 影響

- `docs/design.md` の部品の表に、Timeline（棒・依存の矢印・今日の線・切り替え）を足す
- ボード（#137）の決定とは関係しない
