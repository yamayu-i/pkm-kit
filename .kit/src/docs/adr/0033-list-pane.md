# ADR-0033: 一覧の View を左の固定ペインに、そこから開くノートを右のノートペインに出す

- 状態: 承認
- 日付: 2026-11-03

## 背景

- vault-task の View（Daily、Issues、Inbox など。ADR-0009）と vault-template の一覧 View（Daily notes、Notes、Sources。ADR-0026）は、issue やノートを選んで開くための「親」の画面である。それなのに、ノートと同じタブ列に兄弟のタブとして開いていた（`getLeaf("tab")`）
- 一覧から issue を開くと `getLeaf(false)` が、最後に使ったノートのタブか新しいタブを選ぶ。一覧と issue を並べて見られず、タブが増え、一覧のタブもノートに紛れる

## 決定

### 一覧ペインとノートペイン（PC とタブレット）

- **一覧ペイン**: メイン領域の左側のタブグループ。一覧の View はすべてここにタブとして開き、固定（`setPinned(true)`）する
  - 一覧の View: View の種類が `vault-task-` か `vault-template-` で始まるもの。ただし左サイドバーの `vault-task-sidebar`（ADR-0021）は除く
  - 一覧の View を開くとき、すでに開いていればそれを表示する（今までどおり）。まだなく、一覧ペインがあれば、そこに新しいタブで開く。一覧ペインもなければ、最後に使ったメイン領域のタブを左右に分け、その左に開く（`createLeafBySplit(leaf, "vertical", true)`）。幅は Obsidian の既定の半分ずつ
- **ノートペイン**: 一覧ペインと同じウィンドウにある、一覧ペイン以外のタブグループ
  - 一覧ペインがあるとき、プラグインの中からノートを開く操作（一覧の行、ボード、サイドバー、issue 画面の親子のリンク、テンプレートから作ったノート、今日のデイリーノート）は、ノートペインで開く。最後に使ったノートペインのタブを使い、Ctrl/Cmd+クリック（新しいタブ）のときはそのタブグループに新しいタブを足す
  - ノートペインがなければ（閉じたなど）、一覧ペインの右に分けて作る
  - 一覧ペインがないときは、今までどおり `getLeaf(false)` で開く
- すでに開いている一覧の View の場所は動かさない（固定だけする）。今までのレイアウトでノートと同じタブ列にあるものは、閉じて開き直すと一覧ペインに移る

### スマホ

- スマホ（`Platform.isPhone`）には画面の分割がないので、一覧の View はタブで開いて固定するだけにする。ノートは `getLeaf(false)` で開く。固定したタブは使い回されないので、ノートは 1 つのノートのタブを使い回して開く

### 実装の置き場所

- 2 つのプラグインが同じ規則で一覧ペインを見分けるため、規則と処理を `.kit/src/packages/shared/` に 1 つだけ置き、各プラグインが相対パスで import してバンドルする（`design` の色の計算と同じ使い方）。`shared` は Obsidian の値を import せず型だけを使うので、テストは偽の workspace で書ける

## 理由

- 一覧は issue の親であり、親を左に固定して子を右に開くと、一覧を見ながら 1 件ずつ開いて片付けられる。固定すると、Obsidian の他の操作（ファイルエクスプローラーなど）でも一覧のタブが置き換わらない
- 見分ける規則を View の種類の接頭辞にしたのは、起動時に読み込みを後回しにされたタブ（中身の View がまだない）でも `getViewState().type` で見分けられるため。CSS のクラスで見分ける方法は、後回しのタブで使えない

## 却下した案

- **一覧の View を右サイドバーに置く**: ADR-0021 と同じ理由で、ボードや一覧表にはサイドバーの幅が狭い
- **一覧ペインを 1 つのタブにして、View を切り替えるたびに中身を差し替える**: View ごとの絞り込みやスクロールの状態が切り替えのたびに消える
- **各プラグインに同じ処理を別々に持つ**: 一覧ペインの見分け方がずれると、片方の一覧がノートペイン扱いになる

## 影響

- ADR-0009 と ADR-0026 の「一覧の View をメイン領域のタブで開く」、ADR-0021 の「サイドバーの行はメイン領域のタブを開く」は、一覧ペインに開くことに変わる
- vault-task・vault-template の `main.js` が変わる。子のノートや設定には手を入れない（移行はない）
- Obsidian のレイアウト（`.obsidian/workspace.json`）に、左右の分割と固定が保存される
