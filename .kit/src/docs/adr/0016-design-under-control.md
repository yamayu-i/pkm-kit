# ADR-0016: デザインを管理下に置く（トークンの一元化、Obsidian の外観の固定、検査）

- 状態: 承認
- 日付: 2026-10-31

## 背景

ADR-0013 で UI を Material 3 寄りにし、ルールを docs/design.md に書いた。ただし次の問題があった。

- 値の根拠が書かれておらず、同じ値を作り直せない（色は手で選んだ 16 進、間隔は 6 / 10 / 14px が混在）
- ルールを守っているかを確かめる手段がなく、文章と CSS が食い違っても気づけない
- 色を Obsidian の CSS 変数から作っていたので、テーマによって背景が変わり、コントラストを保証できない。実際、ライトの amber の印は 1.93:1、実行日の白文字は 4.21:1 で WCAG を満たしていなかった。Obsidian の標準の `--text-faint` も白の上で 4.5:1 に届かない
- フォーカスの枠、動きを減らす設定への対応がなかった

Vault の `.obsidian/` はリポジトリでコミットしているので、Obsidian 側の外観もこちらで固定できる。

## 決定

- **根拠の優先順位**: WCAG 2.2 AA > design.md とトークン > Material 3（material-web の tokens v0_192、material-color-utilities）> Obsidian。M3 と違うところは design.md に理由と一緒に書く
- **正本を 1 つにする**: デザインの値は `.plugin-src/packages/design/tokens.json`（Design Tokens Format Module 2025.10）にだけ書く。プラグインの CSS 変数、Obsidian のスニペット、値の一覧の文書、TS の定数はそこから生成し、コミットする
- **Obsidian 側を固定する**: `.obsidian/appearance.json` でコミュニティテーマ・半透明を使わず、アクセントカラーをトークンに合わせ、生成したスニペット `vault-theme.css` だけを有効にする。スニペットで Obsidian 本体の色の変数をトークンと同じ値に固定する。フォントは端末ごとに違うので固定しない
- **プラグインの CSS は Obsidian の色の変数を使わない**: ADR-0013 の「文字・背景・アクセントは Obsidian の CSS 変数から作り、テーマに追従させる」を置き換える。ライト / ダークの切り替え（`body.theme-dark`）には引き続き追従する
- **検査で守る**: ルールのうち機械で確かめられるものは検査にする。`pnpm check` で、トークンの書式とコントラスト（ライト / ダーク）、生成物の鮮度、CSS の書き方、Obsidian の設定、design.md の記述を確かめる。`pnpm preview:ui` で描画した画面のコントラスト・押せる大きさ・フォーカス・キーボード操作を確かめる。`pnpm task:lint` で labels.json の色を確かめる
- 色は当面、手で選んだ値を検査で保証する。HCT による生成は、色を増やすときに改めて考える

## 理由

- 値を 1 か所に置いて生成すれば、文書と CSS と Obsidian の設定が食い違わない。食い違いは検査で見つかる
- 背景を固定しないと、コントラストの検査が「標準のテーマならたぶん大丈夫」以上にならない
- 文章だけのルールは守られなくなる。検査にしておけば、Claude Code が UI を変えたときも同じ基準で止まる

## 却下した案

- **material-color-utilities で色を生成する**: 色の作り方は再現できるが、依存が増える。今の色数（8 色相）なら、手で選んだ値をコントラストの検査で保証すれば足りる
- **Style Dictionary などのトークン変換ツールを使う**: 依存が増える。必要な出力は 4 種類で、自前の 100 行程度の生成で足りる
- **Obsidian のテーマに追従したまま、標準テーマの値で検査する**: テーマを変えた途端に保証が崩れる
- **Obsidian 本体の色の変数（`--color-base-*` など）をすべて上書きする**: 影響が広く、Obsidian の更新で壊れやすい。プラグインが使う面と文字、アクセント、エラーだけを固定する

## 影響

- vault-task の CSS 変数の名前が M3 の役割名になった（`--vt-surface` → `--vt-surface-container` など）
- 間隔を 4px 刻みにそろえ、文字の大きさを px のトークンにしたので、見た目が少し変わった（余白が 2px 前後、曜日が 10px → 11px など）
- `.obsidian/appearance.json` を変えたので、すべての端末でアクセントカラーが変わり、コミュニティテーマとほかのスニペットが無効になる
- Obsidian 本体での見た目（スニペットが効いているか）は、Obsidian で開いて確かめる必要がある（プレビューはスニペットを読み込んで近似している）
- 押せる大きさは WCAG の最小（24px）に合わせた。モバイル向けに 40px 以上にするかは今後決める
