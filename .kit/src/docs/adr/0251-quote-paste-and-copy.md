# ADR-0251: 引用の中への複数行の貼り付けと、引用・コールアウトのコピーボタン（pkm-markdown）

- 状態: 承認
- 日付: 2026-11-27

## 背景

[Issue #251](https://github.com/yamayu-i/pkm-kit/issues/251)。引用（`> `）の中で Enter を押すと、Obsidian 本体が次の行にも `> ` を付けるので、引用の中で改行できる。ところが複数行の文を貼り付けると、本体は記号を付けないので、2 行目から下が引用の外に出る。

貼り付けでも全体が引用の中に入るようにすると、引用の生の文（`>` を除いたもの）を範囲選択でコピーしにくくなる（`>` が混ざる）。インラインコードのコピーボタン（[ADR-0128](0128-markdown-view.md)）と同じように、引用にもボタンがほしい。コールアウト（`> [!note]`）も同じ引用の記法なので、同じく扱う。

## 決定

pkm-markdown に次の 2 つを足す。判定は Markdown のソースの行だけで行う（構文木は使わない。`src/core/blockquote.ts`）。

### 1. 引用の中への貼り付け

- Obsidian の `editor-paste` イベントで、次のすべてを満たすときだけ処理する。ほかは本体に任せる
  - カーソルが 1 つ
  - 選択の始まりの行が引用の行（頭に `>`。前の空白は 3 つまで）で、位置が記号より後ろ
  - 貼る文字が複数行（クリップボードにファイルがない）
- 2 行目から下の頭に、カーソルの行と同じ記号（`> `、入れ子なら `> > `）を付けて貼る。途中の空行には末尾の空白を除いた記号（`>`）だけを付け、引用を切らない。改行は LF にそろえる
- HTML を含む貼り付けは、本体の「HTML を自動で変換」（`autoConvertHtml`）が有効なら `htmlToMarkdown` で Markdown にしてから記号を付ける。この設定は公開の API にないので `vault.getConfig` で読み、読めなければ既定（変換する）とみなす
- モバイルでも動かす

### 2. 引用・コールアウトのコピーボタン

- コピーするのは生の文: ソースの行から外側の記号を 1 段だけ外したもの。太字・リンクなどの記法と、入れ子の引用（1 段残る）はそのまま。コールアウトは 1 行目（`[!type] 題`）を除いた本文
- 見た目と動きはインラインコードのボタンと同じ（`createCopyButton`）。置く場所はブロックの右上の内側
- 閲覧モード: 節の直下の `blockquote` と `.callout` にボタンを付ける。中身は押したときに `getSectionInfo` で節のソースを読んで作り、読めないとき（埋め込みなど）は表示されている文字（コールアウトは本文の部分）。リストの中や入れ子の引用には付けない（節のソースと対応が取れないため）。ホバーのない端末ではタップで出す
- ライブプレビュー（デスクトップのみ。ADR-0128 と同じ理由）: 浮かせるボタンをインラインコードと共用する。インラインコードの上ではインラインコードを優先する
  - 引用の行（`.cm-line.HyperMD-quote`）: ひと続きの引用（記号のある行が続く範囲）の 1 行目の右上に出す。編集中も出す
  - 描かれたコールアウト（`.cm-callout`）: 右上の、本体の「編集」のボタン（`.edit-block-button`）の左に出す

## 理由

- 本体の挙動（Enter で記号を続ける）に貼り付けを合わせるのが、使う人の予想に最も近い
- `editor-paste` は Obsidian の公開のイベントで、モバイルでも効く。CodeMirror の transaction filter で貼り付けを書き換える方法は、本体の HTML の変換がどの userEvent で入るかが公開されていないので取らない
- 処理する条件を狭く（引用の中・複数行・カーソル 1 つ）すると、画像の貼り付けや、URL を選択に貼ってリンクにする本体の機能に触れない
- コピーを表示の文字ではなくソースにするのは、貼り付けと往復できる（別の引用に貼るとそのまま引用になる）ため。記号は外側の 1 段だけ外し、構造（入れ子）を残す

## 却下した案

- **引用全体を貼り付けで書き換える（すべての行に記号を付け直す）**: 貼った範囲の外を変えることになり、取り消しの単位も分かりにくい
- **コピーで表示されている文字だけを取る**: 記法（リンク・太字）が落ち、貼り直すと元に戻らない。ソースが読めないときの代わりにだけ使う
- **ボタンを引用の外側（上の行）に出す**: 引用は幅いっぱいの行なので、上の行の文字に重なる。内側の右上に置く（コードブロックのコピーボタンと同じ位置）

## 影響

- 変更: `.kit/src/packages/pkm-markdown/`（`src/core/blockquote.ts`、`src/obsidian/paste.ts`、`reading.ts`、`live-preview.ts`、`main.ts`、`styles.css`、テスト）、ビルドの成果物 `.obsidian/plugins/pkm-markdown/`
- 依存の追加なし。子の Vault の移行なし（プラグインの更新だけ）
- セキュリティ: 貼り付けのイベントで渡されたクリップボードの中身を読むが、エディタに書く以外に使わない。外部に通信しない
