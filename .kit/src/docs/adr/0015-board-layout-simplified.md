# ADR-0015: task board のグループの並べ方を簡単にし、カードの ID を外す

- 状態: 承認
- 日付: 2026-10-31

## 背景

ADR-0014 では、ボードを横 4 段のグリッドにし、グループごとに横幅（span）を選べるようにした。子グループはグループの中に横に並べた。
使ってみると、横幅の指定は編集の手間に見合わず、グループの編集画面も分かりにくかった。カードは幅が狭く、ID のバッジが表題の表示を圧迫していた。

## 決定

- **1 階層目（グループ）はボードに横に並べる**。幅は等分。狭いペインでは縦に並べる
- **2 階層目（サブグループ）はグループの中に縦に並べる**
- 横幅（`span`）はなくす。`issue/board-groups.json` に残っている `span` は読み捨てる（書き戻すときに消える）
- グループの編集画面（Board groups）は、グループ名・サブグループ名をその場の入力欄で作る・変える。名前の検査（空・`/`・同じ階層で重複）を入力欄の下に出し、エラーがあるあいだは保存できない。上にボードでの並び方の小さな見本を出す
- task board のカードから ID のバッジを外し、表題を優先する（ID はカードの表題にマウスを乗せると出る）。未完了の一覧などの行表示には ID を残す

## 理由

- グループの数は多くないので、等分で足りる。横幅を選ぶ操作がなくなれば、編集は名前と順番だけになる
- 縦に積むサブグループは、午前 → 集中 / 雑務 のような時間帯や作業の区切りと相性がよい
- カードでは何の作業かが分かることが大事で、ID は issue を開けば分かる

## 影響

- ADR-0014 の「グループ」の節のうち、横 4 段・span・子グループを横に並べる部分を置き換える
