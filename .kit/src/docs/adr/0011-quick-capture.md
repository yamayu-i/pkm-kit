# ADR-0011: ショートカットでの issue 一括登録

- 状態: 提案
- 日付: 2026-10-31

## 決定（案）

- コマンド「issue をまとめて作成」を用意する。ホットキーは Obsidian の設定で割り当てる（既定のキーは付けない。他のコマンドとぶつからないように）。モバイルではツールバーかリボンに置く
- モーダルにテキストエリアを 1 つ置く
  - 1 行 = 1 issue（summary だけ）
  - 空行は無視する。行頭の `- ` / `* ` / `- [ ] ` / `1. ` は取り除く（箇条書きを貼り付けられるように）
  - 「N 件作成します」と件数を表示する
  - Enter は改行、Mod+Enter で作成（モバイルではボタン）
- 作られる issue はすべて Inbox（`status: open`、日付なし、priority は空）。本文は既定の見出し（ToDo / Description / Note）
- ID は上から順に連番で振る
- 作成後、5 秒間トーストを出す: 「3 件の issue を作成しました（i-12〜i-14） [すべてタブで開く]」
  - ボタンを押すと、作った issue をそれぞれ新しいタブで開き、最初の 1 件にフォーカスする
  - 一部の作成に失敗したら、トーストにその件数も出す
- トーストは Obsidian の `Notice`（DocumentFragment と表示時間 5000ms）で作る

## 未確定
