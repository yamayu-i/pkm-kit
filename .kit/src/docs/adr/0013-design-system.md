# ADR-0013: UI のデザインは Material 3 を参考にし、ルールを docs/design.md に残す

- 状態: 承認
- 日付: 2026-10-31

## 背景

最初の issue 画面は、Obsidian の標準の部品に近い素朴な見た目で、古く見えた。どこが編集できるのかも分かりにくかった。
今後 View を増やすので、見た目のルールを決めて揃えたい。

## 決定

- UI は Material 3 を参考にする（トーナルな面の色、角丸、チップ、state layer、文字の階層）
- 文字・背景・アクセントは Obsidian の CSS 変数から作り、テーマに追従させる。status などの色はライト / ダーク両方を定義する
- 編集できるものは「枠線 + 明るい面 + 操作を表すアイコン」、読み取り専用は「枠なし + 沈んだ面」で見分けられるようにする
- 狭いペインへの対応は、画面幅ではなくペインの幅（container query）で行う
- ルールの詳細は [docs/design.md](../design.md) に置き、UI を変えるときはそれに従う。見た目は `pnpm preview:ui` のスクリーンショットで確認する

## 理由

- 一度決めたルールがないと、View ごとに見た目がばらつく
- Obsidian の変数から作れば、ユーザーのテーマやアクセントカラーを変えても破綻しない

## 却下した案

- **Material の CSS ライブラリを入れる**: 依存が増え、Obsidian の見た目とも衝突する。トークンと少しの CSS で足りる
