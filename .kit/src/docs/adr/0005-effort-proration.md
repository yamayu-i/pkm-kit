# ADR-0005: 実績工数は重複を按分して都度計算する

- 状態: 承認
- 日付: 2026-10-31

## 背景

task board ではグループ単位で再生できるので、時間の重なった worklog ができる。そのまま足すと、1 時間の作業が N 件 × 1 時間として計上される。

## 決定

- 時間が重なっている区間だけ、同時に動いているログの数 k で割って配る
  - 例: A が 10:00〜11:00、B が 10:30〜11:00 → A = 30 + 30/2 = 45 分、B = 15 分
- 計算は全 worklog の開始と終了を時刻順に並べて 1 回なめる（スイープ、O(n log n)）
- 動いているログ（`to` が `null`）は「今」までとして計算する
- 結果は保存しない。メモリ上の索引に持ち、ログが変わったら、その時間帯に重なるログに関わる issue だけ再計算する
- issue 画面に出すのは按分後の値だけ

## 理由

- 1 日 10 件で年 3,650 件として、数年分でも数 ms で計算できる
- 按分した値は他の issue のログを直すだけで変わる。保存すると、1 件直すたびに関係する別の issue の md まで書き換えることになり、コンフリクトの種になる

## 却下した案

- **`real_effort` を frontmatter に保存する**：上の理由
