# ADR-0154: リボンの「Tasks Now」ダイアログ

- 状態: 承認（一部置換: 0184）
- 日付: 2026-11-15

## 背景

今の状態（Organize を後回しにしていないか、記録を止めたままにしていないか、働き続けていないか）と、動いているタスクの操作は、複数の View に散っている。休憩のために記録をまとめて止め、あとで同じ群を再開する操作もない。リボンから 1 回で開き、今やることだけが見えるダイアログを足す。

## 決定

- リボンに「Tasks Now」（アイコン `timer`）を足す（pkm-ribbon の表。ADR-0029、ADR-0070）。押すと pkm-task のコマンド `pkm-task:open-tasks-now` を呼び、モーダルを開く。ノートや View は作らない
- ダイアログの中身は上から次のとおり
  1. **現在日時**: `2026-11-15 SUN 14:03:09` の形で、1 秒ごとに更新する
  2. **PKM State**: 横並びのカード（狭い画面では折り返す）。色だけに頼らず、文字でも状態を出す
     - **Organized**: 前に Organize してからの経過時間。1 日以上で赤、それ未満は緑。前回は、Organize が書く `reviewed` のうちいちばん新しい日の 0 時と、この端末が最後に Organize で記録した時刻（設定 `lastOrganizedAt`）の新しい方。どちらもなければ赤の `Never`
     - **Worklog Paused**: 前に記録を止めてからの経過時間（worklog の `to` のいちばん新しいもの）。12 時間以上で赤、それ未満は緑。記録中は経過時間を出さず `Running`（緑）。記録が 1 件もなければ赤
     - **Focus Streak**（要望の「Rest」。働き続けた長さを見るので、この名前にした）: 記録中のうち、いちばん前に始めたタイマーの経過時間。1 時間未満は緑（Healthy）、1 時間以上 2 時間未満は黄（Caution）、2 時間以上は赤（Over-focused）。記録中がなければ色なしの `Resting`
  3. **実行中のタスク群**: 記録中のタスクをカードで出す（同じ鍵の複数のログは 1 つ。長い順）。群全体に次の 2 つのボタンを置く
     - **Pause**: 記録をすべて止めて集計する（1 分未満は残さない。ADR-0004）。止めた群の鍵を端末の設定（`pausedTasks`）に保持する。群は「Paused」として残り、**Resume** で同じ群を一括で始められる。**Discard** で群を捨てる
     - **Stop**: 記録をすべて止めて集計し、群は保持しない
     - 保持した群のうち、消えた・closed / canceled になったものは再開の対象から外す。別のタスクを始めた（記録中が 1 つでもある）あいだは、保持した群を出さない
  4. **タスクリスト**: 今日のボード（今日が実行日で自動で載るものを含む。ADR-0034）のうち、記録中でも保持中でも片付いてもいないものを、Top 3 → Up next → Waiting の順にリストで出す。行の再生ボタンで記録を始めると、実行中のタスク群に移る（ADR-0137 のボードの欄と同じ分け方）
- **ホットキー**: コマンド `pkm-task:open-tasks-now`（Open Tasks Now）として登録するので、Obsidian の設定「ホットキー」で割り当てられる。上流は既定のキーを決めない（子ごとの `hotkeys.json` で、ほかの割り当てとぶつかるため）
- **ダイアログのキー**（開いているあいだだけ）: **Space** は実行中なら Pause、保持中なら Resume（再生・一時停止のトグル）。**Shift + Space** は実行中なら Stop、保持中なら Discard。どちらも対象がなければ何もしない。操作中（`busy`）は押しても重ねて実行しない
- **Cmd + W**: プラグインが作るすべてのダイアログ（モーダル）は、Cmd + W（Windows / Linux は Ctrl + W）で閉じられる。Obsidian の既定の Mod + W は背後のタブを閉じるので、モーダルの scope で先に受けて止める。共通の `registerCloseKey`（`packages/shared/src/modal-keys.ts`）を、モーダルを作る側が呼ぶ。新しいモーダルを足すときも呼ぶ
- **バッジ**: リボンの Tasks Now に、記録中のタスクの数（同じ鍵は 1 つ。0 なら出さない）をバッジで出す。pkm-task が `getRibbonBadge` で数を答え、変わったときだけ pkm-ribbon に知らせる（ADR-0070 の 6）
- 行の題を押すとそのノートを開く。再生・停止は既存の `startTimer` / `stopTimer`（open の issue とサブは in-progress にする。ADR-0031）を使う
- 保持する群と前回の Organize は端末ごとの設定（`data.json`。git に入れない）に置く。worklog・board・statuslog の形式は変えない

## 理由

- 状態の 3 つは、どれも既にある記録（`reviewed`、worklog）から計算できる。新しい記録の形を増やさずに済む
- 休憩は「止める」と「あとで同じ群を始める」の組なので、群を保持する Pause と、保持しない Stop を分ける。保持は集計の外の操作なので、worklog には何も足さない
- 色の閾値は要望のとおり。区切りは「以上」で赤・黄にする（ちょうど 1 日・12 時間・1 時間・2 時間で次の色）

## 却下した案

- **Organize の記録を新しい jsonl に書く**: 端末間で正確な時刻が取れるが、形式と移行が増える。`reviewed`（日付）と端末の時刻で足りる。ただし別の端末で Organize したときの精度は日単位になる
- **保持した群を worklog に書く**: 止めた記録と区別がつかなくなり、集計と lint が複雑になる
- **View として開く**: 要望がダイアログで、ほかの作業を中断せず見られることが目的

## 影響

- pkm-task: コマンド `open-tasks-now`、モーダルの部品、設定 2 項目、styles を足す。Organize の確定で `lastOrganizedAt` を書く。pkm-ribbon: 表に 1 行足す
- 子の Obsidian の設定やノートは変えないので、移行は付けない。ビルド済みの `.obsidian/plugins/` が変わるので、子は取り込むだけでボタンが出る
- 文言（ボタン・カードの名前）は画面に出る英語、通知は日本語（ADR-0143 と同じ）
