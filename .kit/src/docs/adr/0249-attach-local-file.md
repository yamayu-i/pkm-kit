# ADR-0249: @file と /file で、ローカルのファイルを asset/ に置いてリンク・埋め込みを入れる

- 状態: 承認
- 日付: 2026-11-27

## 背景

ノートにローカルのファイル（画像・PDF など）を添付するとき、規約（`asset/` 直下に置き、Vault ルートからのパスの Markdown リンクで参照する）どおりに入れる手段がない。Obsidian の標準の添付（ドラッグ＆ドロップ・貼り付け）は設定しだいで置き場所とリンクの書式が変わる。

`@` のインラインテンプレートと `/` のスニペットは、`command:` を持つものを選ぶと、打った文字を消してコマンドを実行する（[ADR-0094](0094-snippet-command.md)、[ADR-0194](0194-at-link-insert-and-inline-chips.md)）。これに乗せる。

## 決定

- pkm-template にコマンドを 2 つ足す
  - `insert-file-link`（Insert file as link）: OS のファイル選択（エクスプローラー・Finder、モバイルではファイルピッカー）を開き、選んだファイルを `asset/` に置いて `[名前](asset/…)` を入れる
  - `insert-file-embed`（Insert file as embed）: 同じく置き、プレビューできる種類は `![名前](asset/…)` で埋め込む。それ以外は `insert-file-link` と同じリンクにする
- 上流の既定に、インラインテンプレート `.kit/templates/inline/file.md`（`alias: file`、`insert-file-link`）とスニペット `.kit/templates/snippet/file.md`（`alias: file`、`insert-file-embed`）を足す
- プレビューできる種類は、Obsidian が埋め込みで表示できるもの: 画像（png・jpg・jpeg・gif・bmp・svg・webp・avif）、PDF、音声（mp3・wav・m4a・flac・ogg・oga・opus・3gp）、動画（mp4・webm・ogv・mov・mkv）
- 複数のファイルを選べる。`/file` は 1 行に 1 つ、`@file` は半角空白で区切って入れる
- 1 ファイル 20MB を超えるものは置かず、そのファイル名を知らせる。ほかのファイルは置く
- ファイル名: 空白（連続も）はハイフン 1 つに、ファイル名に使えない文字・リンクを壊す文字（`\ / : * ? " < > | # ^ [ ] ( ) %`）もハイフンにする。ハイフンが続けば 1 つにし、拡張子の前後と先頭・末尾のハイフンを除く。日本語はそのまま。拡張子は小文字にする
- 同じ名前が `asset/` にあれば、拡張子の前に `-1`、`-2`…を付ける。既存のファイルを上書きしない
- リンクの表示テキストは、置いたファイル名（`@file` は拡張子まで、`/file` の埋め込みは拡張子を除く）
- `asset/` がなければ作る

## 理由

- 既存の `command:` の仕組みに乗せれば、候補の出し方・打った文字の消し方を新しく作らずに済む
- `/` は行頭でだけ出るので、ブロックとしての埋め込みに合う。`@` は文中でだけ使うので、いつもリンクにする
- `asset/` は git で同期し、履歴に残り続ける。大きいファイルを気軽に入れると、すべての端末の Vault が重くなるので上限を設ける
- ファイル名の空白を `%20` にするとリンクが読みにくい。置くときに置き換えるほうが、リンクも asset/ の一覧も読みやすい

## 却下した案

- Obsidian の標準の添付（ドラッグ＆ドロップ・貼り付け）の挙動を変える: 本体の設定と処理に踏み込むので、別に扱う
- 上限を超えたファイルも確認のうえ置く: 確認を押せば入るので、履歴が膨らむのを防げない
- 同じ中身のファイルがあれば、それを使い回す: 中身の比較に全ファイルを読む必要があり、名前が違えば別のものとして扱うほうが分かりやすい

## 影響

- 子の Vault: 上流のテンプレートの既定が増えるだけで、移行はない。子が同じ名前（`file.md`）のスニペット・インラインテンプレートを持っていれば、子のものが優先する
- 外から持ってきた SVG も `asset/` に置かれる。図の SVG の検査（`diagram.mjs svg-check`）は明示して呼んだときだけ動くので、`verify.mjs` は止めない
