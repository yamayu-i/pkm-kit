# ADR-0163: Timeline で依存（depends_on）を引く・消す

- 状態: 承認
- 日付: 2026-11-15

## 背景

ADR-0143 の Timeline は、依存を矢印で表示するだけだった。追加・削除は Edit ダイアログの「Depends on」（ADR-0142）でしかできず、図を見ながら順番を決めるときに画面を行き来する。期間をドラッグで直せるのと同じように、依存も図の上で直したい（#163）。

## 決定

ADR-0143 の「操作」に、次を足す。保存と検査は期間と同じ（指を離したときに 1 回、ADR-0135 の検査。通らなければ日本語の通知を出して元に戻す）。

### 引く

- 棒の右端に、つなぐための小さな丸（コネクタ）を置く。棒にホバーかフォーカスしたときと、タッチ操作のときに出す。期間の伸ばし用のつまみ（右端 8px）とは別の場所（右端の外側）に置く
- コネクタから別の棒へドラッグすると、「ドラッグを始めた棒が、離した棒の依存先になる」（`depends_on` に始めた棒の id を足す）。矢印の向きと同じ: 始めた棒の右端から、離した棒の左端へ
- ドラッグ中は、コネクタからポインタまでの仮の線（primary の色の破線）を出す。つなげる棒には primary の枠を付け、つなげない棒（自分自身・すでにつないである・循環になる）は薄くする。つなげない棒の上で離したら何もしない
- 期間のない行（棒がない行）はつなげない。先に期間を決める

### 消す

- 矢印を押すと選ぶ（中ほどに × ボタン（24px）を出し、矢印の周りを primary で薄く塗る）。矢印の線は細いので、押せる範囲は線の左右 6px ずつに広げる
- 選んだ矢印は、× ボタンか Delete / Backspace キーで消す。選びなおすか、ほかを押すか、Esc で選択を外す
- つなぎ替えは「消して、引き直す」。専用の操作は作らない

### キーボード

- 引く・選ぶ操作は、ポインタ（マウス・指）だけにする。矢印の当たり判定は線に沿った細長い領域で、Tab で順に選ぶ要素にすると、近くの棒の押せる範囲と重なる（描画の検査 `run/target-size` に通らない）。キーボードでは、題の Edit ダイアログの「Depends on」を使う（今までどおり。同じ結果になる）
- 矢印を選ぶと、× ボタンにフォーカスが移る。そこで Delete / Backspace を押しても消せる

### 文言

`aria-label`・ツールチップは英語（例: `Connect: drag to a bar that depends on this`、`Remove dependency`）、通知は日本語（`依存を保存できませんでした`）。

## 理由

- 順番を決めるのは、棒の位置関係を見ているとき。そこで直接つなげれば、ダイアログを開かずに済む
- 「始めた棒から、あとの棒へ」の向きは、矢印の向き（依存先 → 依存するサブ）と同じで、引いたとおりの矢印ができる
- 検査は書く側（`checkSubIssues`）が持っているので、図の側は同じ規則で「つなげない棒」を示すだけでよい。ずれても、書く前の検査が止める
- 消すのを矢印の選択にすると、ダイアログのチェックを外すのと同じ結果を、図の上でできる。つなぎ替えを別の操作にすると、操作が増えて説明が要る

## 却下した案

- **2 つの棒を順にクリックする**: 手数は同じで、何を選んでいる最中かが分かりにくい。タッチでは棒のタップ（Edit を開く）と区別しにくい
- **ドラッグを、依存する側の棒の左端から始める**: 矢印の向きと逆で、「何に依存するか」を先に考えることになる。期間の左端のつまみとも近すぎる
- **追加だけにして、削除はダイアログ**: 間違えて引いたときに、図から離れないと直せない
- **矢印の端をつかんで、つなぎ替える**: 線が細く入り組むので、端をつかみにくい。実装も大きい
- **期間のない行にもつなげる（矢印は出ない）**: 引いても何も変わらないように見え、迷う

## 影響

- `docs/design.md` の部品の表の Timeline に、コネクタ・選んだ矢印・× ボタンを足す
- ADR-0143 の「操作」から、この ADR を参照する
- 子のものは変わらないので移行はない。`.kit/changes/` に記録を足す
