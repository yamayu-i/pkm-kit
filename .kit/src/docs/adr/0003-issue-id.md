# ADR-0003: issue の ID は `i-N` の連番

- 状態: 承認
- 日付: 2026-10-31

## 決定

- ID は `i-N`（N は 1 から始まる連番）。ファイル名も `issue/i-N.md`
- 作成時に、索引にある最大の N + 1 を採番する
- 2 台がオフラインのまま同時に作って ID が重複した場合は、lint で検出して手で直す（後から作った方の番号を振り直し、参照も書き換える）

## 理由

- 人も LLM も読みやすく、口頭やメモで参照しやすい
- 2 台で同時に新規作成することはまれなので、重複は手で直すことで受け入れる

## 却下した案

- **端末ごとの接頭辞（`i-m12` など）**：重複はしないが、読みにくくなる
- **nanoid**：人や LLM が読めない

## 影響

- 重複すると、同じパスへの追加同士がぶつかり（add/add コンフリクト）、md にマーカーが入る。lint はこれも検出する
