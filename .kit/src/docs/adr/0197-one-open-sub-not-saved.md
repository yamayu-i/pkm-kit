# ADR-0197: issue 画面で開けるサブを 1 つだけにし、開閉の状態を保存しない

- 状態: 承認
- 日付: 2026-11-16

## 背景

[Issue #197](https://github.com/yamayu-i/pkm-kit/issues/197)。下部のサブのカード（ADR-0161）は、いくつでも同時に開け、開閉の状態をこの端末の `data.json`（`subOpen`）に保存している（ADR-0158）。

実際に使うと、同時に開くのは 1 つで十分だった。開いたまま残ると、あとで開き直したときに本文が長く広がり、目的のサブを探しにくい。

## 決定

### 開けるのは 1 つだけ

- issue のノートごとに、開いているサブは多くても 1 つ。別のサブを開くと、前に開いていたサブは閉じる
- 開いているサブを閉じると、どれも開いていない状態になる
- 「Open note」（ADR-0179）も同じ。そのサブを開き、ほかは閉じる
- 同じ issue を 2 つのペインで開いているときは、開いているサブを共有する（Live Preview と Reading で同じ）

### 開閉の状態を保存しない

- 開いているサブは、プラグインの中（メモリ）だけで持ち、`data.json` に書かない。既定は、すべて閉じている
- そのノートを表示しているペインがなくなったら（タブを閉じた、同じタブで別のノートへ移った）、忘れる。次に開くと、すべて閉じている
- 同じペインで Live Preview と Reading を切り替えたときや、ノートを編集して描き直したときは保つ
- Obsidian やプラグインを起動し直したら、すべて閉じている
- 「Show N closed」（ADR-0181）の出す・隠すも、同じ時に忘れる（今は起動し直すまで残る）
- 今の `data.json` の `subOpen` は読まない。次に設定を保存したときに消える

### 切り替えたときのスクロール

- 別のサブを開いたとき、前のサブが押した行より上にあれば、その本文が消えて押した行が上へ動く。ADR-0179 のとおり、押した題の行の画面上の位置を保つようにスクロールを戻す（文書の先頭に近くて戻し切れないときは、戻せるところまで）
- 上端に浮かんだ行から閉じたときは、今までどおり、そのカードの題を上端に出す

## 理由

- 1 つだけなら、本文が長く広がらず、どのサブを読んでいるかが分かる。開いているサブを探して閉じる手間もない
- 開くのは読む・書くその場のためで、あとで同じ状態に戻したい場面がなかった。保存しなければ、開き直すたびに一覧として見渡せる
- 表示しているペインがなくなるまで保てば、表示の切り替えや編集で描き直しても開いたサブが閉じない

## 却下した案

- **開閉の状態は保存したまま、1 つだけにする**: 開き直したときに前のサブが開いて本文が広がるのは、今の困りごとと同じ
- **ノートを開くたび（`file-open`）に忘れる**: タブを行き来するだけで閉じてしまう
- **ペインごとに開閉を持つ**: 同じノートの 2 つのペインで食い違い、Live Preview と Reading の切り替えでも引き継げない。同じ issue を 2 つ並べる場面は少ない

## 影響

- ADR-0158 の「展開の状態の保持」と、ADR-0161 の「開閉はこの端末に保存する」を置き換える。ADR-0181 の「Show N closed」を忘れる時を変える
- `data.json` の `subOpen` をなくす。`data.json` は端末ごとの設定で git に入れていないので、移行は要らない。`.kit/changes/` に変更を 1 件書く
- 部品の表（`docs/design.md`）のサブの項目のカードの行を直す

## 追記（2026-11-27）: サブへのリンクと、上端に出すときの待ち方

実装のときに、ADR-0179 の「Open note」の動き（サブを開いて下部のカードの題を上端に出す）が、次の場面で届いていなかったので、合わせて直す。

- サブへのリンク（`issue/i-N.md#<サブの id>`。ADR-0194 のチップ）を押すと、issue のノートを開くだけで、サブを開かなかった（アンカーは Obsidian に渡るが、サブの項目は見出しでないので行き先がない）。ノートを開いた後に「Open note」と同じ動きをする。Reading でも同じにするため、サブへのリンクだけは Obsidian の代わりにプラグインが開く
- Projects から開くとき、ノートを開いて 50 ms 待ってから上端に出していた。待つ時間を決め打ちせず、ノートのビューとカードが描かれるまでフレームごとに確かめ直す
- Live Preview: CodeMirror に題を上端へ出させた後、次の数フレームで題の位置を確かめ、ずれていれば直す（画面外の高さの見積もりのずれと、ノートを開いた直後に Obsidian がスクロール位置を戻すことへの備え）
- Reading: カードが DOM にないときは、行番号で近くまでスクロールしてから、遅延描画でカードが描かれるまで何フレームか待って合わせる（これまでは 1 フレームしか待たなかった）
- 同じ issue を Live Preview の 2 つのペインで開いているときも、開閉を変えたらもう一方を描き直す（開いているサブを共有する）
