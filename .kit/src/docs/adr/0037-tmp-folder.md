# ADR-0037: git で管理しない一時ファイルの置き場 tmp/ を作り、temporary/ は使わない

- 状態: 承認
- 日付: 2026-11-08

## 背景

[Issue #14](https://github.com/yamayu-i/pkm-kit/issues/14)。一時的に作るファイルの置き場がない。今は、HTML を Vault の外に渡すために書き出す先が要る（[Issue #44](https://github.com/yamayu-i/pkm-kit/issues/44)）。また、自分が一時的に見るだけで、端末間で同期しなくてよいファイルもある。

一時ファイルの置き場の名前が 2 つある。updated の付与（[ADR-0028](0028-auto-updated.md)）は `temporary/` と `tmp/` の両方を対象外にしている。一方、ノートの規約（`.claude/docs/vault-conventions.md`）の共通 frontmatter の除外には `temporary/` だけが書かれている。どちらのフォルダも、実際にはまだない。

## 決定

### 1. 用途

`tmp/` は、次のファイルを置く場所にする。

- **外部共有用の書き出し先**: Vault の外（ブラウザ、メールの添付、ほかの人）に渡すために、プラグインや CLI が書き出すファイル（#44 の HTML など）
- **自分用の一時ファイル**: 自分が見るためのもので、一時的にしか参照せず、端末間で同期しなくてよいファイル

残したいもの・ほかの端末でも見たいものは、`tmp/` の外のノートにする。

### 2. 置き場所と git

- Vault ルート直下の `tmp/` に置く。中にサブフォルダを作ってよい
- 上流の `.gitignore` に `tmp/` を入れる（merge で各 Vault に届く）。`tmp/` のファイルはコミットされず、端末間で同期されない
- 一時ファイルの置き場の名前は `tmp/` だけにする。**`temporary/` は使わない**。updated の付与の対象外から `temporary/` を外す（ADR-0028 の対象の規則を一部置き換える）。規約の除外の記述も `tmp/` にそろえる

### 3. ノートの規約との関係

- `tmp/` のファイルは、ノートの規約（共通 frontmatter、type、リンクの書式）と、updated の付与・wiki-lint の対象外にする（ADR-0028 で対象外にしていることを、規約にも書く）
- `tmp/` の外のノートから `tmp/` へリンクしない（ほかの端末にはないので、リンク切れになる）
- `tmp/` のファイルは LLM wiki の元資料（`sources/`）として扱わない。取り込むなら `sources/` に保存する

### 4. 寿命

- 自動では消さない。不要になったら人が消す（Obsidian のファイル一覧か、一覧 View から）
- 書き出しを行う機能（#44 など）が、同じファイルを上書きするか日時を付けるかは、その機能の ADR で決める

### 5. 子の Vault ですでに tmp/ をコミットしている場合

- `tmp/` を `.gitignore` に入れても、すでに追跡しているファイルは追跡されたまま残る。追跡を外すと、次に同期したほかの端末から消える
- そのため、移行は追跡を自動では外さない。追跡中の `tmp/` のファイルがあれば一覧を出して止め、人が「`tmp/` の外へ移して残す」か「追跡を外す（`git rm -r --cached tmp`）」かを決める

### 6. 一覧 View

- `tmp/` 専用の一覧 View は別の Issue で扱う（実装の場所、Notes などほかの一覧から `tmp/` を除くか、一覧からの削除を含む）

## 理由

- 名前を 1 つにすると、規約・検査・プラグインの除外の記述がそろい、どちらに置くかで迷わない。`tmp/` は短く、#14・#44 もこの名前で考えている
- 用途の 2 つはどちらも「端末の外に残さなくてよい」ので、git で管理しないことで同期の衝突とリポジトリの肥大を避けられる
- 自動で消すと、書き出した直後に共有する前のファイルや、まだ見ているファイルを消すおそれがある。量は人が見て消せる程度と見込む

## 却下した案

- **`temporary/` も残す**: 置き場が 2 つになり、規約の記述がすでに食い違っている
- **`tmp/` をコミットする**: 同期しなくてよいファイルが履歴に残り、書き出しのたびにコミットが増える
- **一定期間で自動で消す**: 共有前・閲覧中のファイルを消すおそれがある。必要になったら一覧 View の Issue で、手で選んで消す機能として考える
- **移行で追跡を自動で外す**: ほかの端末からファイルが消える

## 影響

- vault-git（`stamp/updated.ts`）と `.kit/bin/stamp-updated.mjs`: `temporary/` を対象外から外す。`temporary/` のノートにも updated が付き、wiki-lint の対象になる
- `.gitignore` に `tmp/` を足す
- `.claude/docs/vault-conventions.md`: 配置の表に `tmp/` を足し、除外の記述を `tmp/` にそろえる
- 移行 `0005-tmp-untracked`: 追跡中の `tmp/` のファイルを見つけて止める（決定 5）。`.kit/CHANGELOG.md` に書く
- ADR-0028 の状態を「一部置換: 0037」にする
