# 0245: サブの期間は start と end を必ずそろえる

## 何が変わったか

`.kit/src/docs/adr/0245-sub-period-pair-and-range-dialog.md`。

- サブの期間（`start` / `end`）は、両方あるか、両方ないかのどちらかにした。片方だけのサブは、書く前の検査（画面・本文のカード・MCP）で止まり、lint が警告（`sub-period-half`）を出す
- 期間は 1 つのダイアログ（Period）で、始まりと終わりを続けて選ぶ。期限だけを持つサブは、`start` と `end` を同じ日にする

## スクリプトが行うこと（migrate.mjs）

`issue/i-N.md` のサブのブロックの項目（`<!-- sub-issue` から `-->` まで）について:

- `start` だけ・`end` だけのサブは、もう片方を同じ日にする（Timeline が今まで描いていた 1 日の棒と同じ姿）
- 空の行（`end:` や `end: null`）があれば置き換え、なければ残っている方の行の隣（`start` は前、`end` は後ろ）に足す
- 直したサブを移行の報告に出す（`node .kit/migrate.mjs --dry-run` で先に見られる）
- ほかの項目、本文、改行コード（CRLF も）は変えない。閉じの `-->` がないブロックには触れない。DailyNote には触れない

## スクリプトで扱えない場合（AI が行うこと）

残っている方の値が日付として読めない（`start: 明日` など）サブは直さず、`check` に残る。ユーザーに日付を確かめ、`start` と `end` を両方入れるか、両方消す。

## 確かめ方（check.mjs）

- `issue/i-N.md` のサブの項目に、`start` か `end` の片方だけを持つものがない
