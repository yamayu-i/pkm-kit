# 0005: tmp/ を git で管理しない

## 何が変わったか

`.kit/src/docs/adr/0037-tmp-folder.md`。

- 一時ファイルの置き場を `tmp/` にそろえた（`temporary/` は使わない）。用途は、外部共有用の書き出し先と、自分が一時的に見るだけで端末間で同期しなくてよいファイル
- 上流の `.gitignore` に `tmp/` を入れた。merge で届き、これから `tmp/` に置くファイルはコミットされない
- `.gitignore` に入れても、すでに追跡しているファイルは追跡されたまま残る。追跡を外すと、次に同期したほかの端末からそのファイルが消える

## スクリプトが行うこと（migrate.mjs）

- 何も変えない。git が追跡している `tmp/` のファイルがあれば、その件数を知らせる

## スクリプトで扱えない場合（AI が行うこと）

`check.mjs` が、git が追跡している `tmp/` のファイルを挙げて止まったとき。ファイルごとに、一覧をユーザーに見せて次のどちらにするかを確かめる（勝手に決めない）。

- **残したい・ほかの端末でも見たい**: `tmp/` の外へ移す（`git mv tmp/<ファイル> <移し先>`）。ノートなら、ノートの規約（frontmatter、置き場所）に合わせ、それを指すリンクも書き換える
- **一時ファイルでよい**: 追跡を外す（`git rm --cached -- tmp/<ファイル>`）。この端末には残るが、ほかの端末では次の同期で消える。ほかの端末にしかない変更がないかを、先にユーザーに確かめる

決めたら、ブランチでコミットしてから `node .kit/migrate.mjs` をもう一度実行する。

## 確かめ方（check.mjs）

- `git ls-files -- tmp/` が空（git のリポジトリでなければ通る）

## 取り込んだ後（人が行うこと）

`tmp/` に置いたファイルは同期されない。ほかの端末でも見たいものは `tmp/` の外に置く。`tmp/` の外のノートから `tmp/` へリンクしない（ほかの端末ではリンク切れになる）。
