# 通常の改行を Reading View でも残す

Reading View だけで通常の改行がつながる差を減らすため、`.obsidian/app.json` の `strictLineBreaks: true` を `false` にする。issue 以外のノートにも適用する。ノート本文は書き換えない。

- ほかの設定とファイル末尾の改行の有無を保持する。2 つの空白で字下げする。
- すでに false・未設定・ファイルなしなら何もしない。未設定時の Obsidian の既定は false。
- `--dry-run` は書き込まず、変更予定だけ返す。再実行は何もしない。
- 壊れた JSON・オブジェクトでない値・真偽値でない strictLineBreaks は変更せず、check で止める。元の設定を確認して直してから再実行する。

適用後は Obsidian を再起動する。通常の改行、空行による段落、末尾の空白 2 つによる改行を含むノートを両モードで開き、通常の改行が維持されることを確認する。連続空行の数や編集用の記号の表示は一致しない。
