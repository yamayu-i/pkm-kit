# 2026-11-08 PKM Git の自動の同期

## つまずき

- 起きたこと: ADR-0089 の状態表示とコマンドの名前を日本語で書いて承認を得た後、実装の途中で ADR-0076（ステータスバー・コマンド名・ボタンは英語）に気づき、ADR の文言を直した
- 改善案: dev-plan の「文脈を読む」に、UI の文言を含む ADR・計画では design.md の「文言の言語」を読むことを足す

## つまずき

- 起きたこと: テストの中で `execFileSync("git", ["push", …])` を、同じプロセスで動くテスト用の git サーバーに向けて実行し、イベントループが止まってテストが固まった
- 改善案: pkm-git のテストの補助（`test/helpers/git-server.ts`）の説明に、「サーバーは同じプロセスにあるので、同期の子プロセスからつながない。ほかの端末の操作は Device の async の API で行う」と書く

## 移行

- 起きたこと: 移行を足すと、0070 のテストが実行された移行の一覧を `deepEqual` で確かめているため、新しい移行のたびにそのテストの期待値を書き足す必要がある（0072 も同じだった）
- 改善案: 0070 のテストを、0070 の結果だけを確かめる形（一覧に 0070 が含まれる）にする
