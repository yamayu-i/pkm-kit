# 2026-11-26 Projects の横スクロールバーの固定

## 訂正

- 起きたこと: 横のスクロールバーを画面の下端に固定するため、図のバーを隠し、中身の高さ 0 の箱のネイティブのスクロールバーを sticky で出した。確かめるときに Obsidian と同じ 12px の常に見えるスクロールバーを注入して撮ったので、オーバーレイ型（macOS の「スクロール時に表示」など）では箱の高さが 0 になり何も出ないことを見落とした。マージ後にユーザーから「横スクロールバーが出てこなくなった」と言われた
- 改善案: ネイティブのスクロールバーの見え方に頼る UI は、プレビューの既定（headless はスクロールバーを隠す。オーバーレイ型に近い）のままでも確かめる。docs/design.md に「いつも見えて押せる必要があるスクロールバーは自前で描く（ScrollRail）」と書いた
