# 2026-11-08 Draw.io の図（pkm-drawio）

## つまずき

- 起きたこと: クラウドのセッションで、指定されたブランチの前の PR（#62）が既にマージされていた。main から作り直してから作業した
- 改善案: なし（環境の手順どおり）

## 食い違い

- 起きたこと: `pnpm security:scan --offline` が「lockfile と package.json が一致している」で失敗した（`pnpm install --frozen-lockfile --offline` が playwright のメタデータを pnpm のキャッシュに持っていない）。lockfile は一致しており、オンラインの `pnpm security:scan` は 8/8 pass。security-check の手順は「ネットワークがなければ --offline」としているが、キャッシュが空の環境では --offline の方が通らない
- 改善案: security-check の手順に「--offline はキャッシュのある環境で使う」と書くか、スキャンが --offline でも lockfile の検査をキャッシュに依存しない形（`pnpm install --frozen-lockfile --lockfile-only` など）にする

## つまずき

- 起きたこと: `pnpm --filter pkm-html preview:ui` が、そのままでは Chromium を起動できなかった（Playwright の既定の場所に版の合うブラウザがない）。`CHROMIUM_PATH=/opt/pw-browsers/chromium` で動いた。文書の「入れられない環境では CHROMIUM_PATH」のとおり
- 改善案: なし（文書どおり）。Issue #49（開発環境を最初に確かめる）の材料

## つまずき

- 起きたこと: 新しいプラグインの CSS で `z-index: var(--layer-popover)`（Obsidian の変数）を使い、design の検査（`var/known`）で止まった。Obsidian の変数はフォントのものだけが許されている。数で書いて通した
- 改善案: design.md の「Obsidian 側の固定」に、重なり（z-index）の書き方を足す
