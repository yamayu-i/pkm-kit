# 2026-11-15 Markdown の表示差

- 起きたこと: Reading View と Live Preview で通常の改行が違うとの報告があった。必須設定が strictLineBreaks: true のため Reading だけ改行をつなぐ。CSS も Reading にだけ指定した余白と深いリストの記号の不足があった。

- 公開準備: 新規 Issue の作成には今回の変更の公開許可が必要だった。許可後に Issue #167 を作成し、検証用の仮番号を Issue 番号へ変更した。
- 検証: 本体の見出し直後の行への指定は、:not と :has の内部まで含む詳細度で比較する必要があった。規則を列挙して原因を特定し、見出し直後のリストを明示した。また、成果物の再現性検査を通常の build と同時に走らせると書き込み中の成果物を読むため、build 完了後に実施する。
