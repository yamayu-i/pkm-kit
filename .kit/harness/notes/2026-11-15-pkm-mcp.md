# 2026-11-15 MCP を PKM 全体に広げる（段階 1）

## 食い違い

- 起きたこと: ADR-0156 の 3 で「一覧は既定 20 件、上限 100 件にし、total と truncated を返す」と決めたが、`task_list_issues` などの task_ の一覧は配列を返し、task-coach と旧名の呼び出しがその形を前提にしている。段階 1 では task_ の一覧の形を変えず（`task_list_issues` は既定 100 件のまま）、新しい群（note_ など）だけを包みにした
- 改善案: 段階 3（旧名を消すとき）に、task_ の一覧も total・truncated・cursor の形にそろえる。ADR を書くときは、既存のツールの互換が要るかを決定の範囲に書く

## つまずき

- 起きたこと: テストの前提を 3 か所誤った（`labels.json` がないと存在しないラベルが問題にならない、本文のリンク先の文字列も検索に当たる、`memo.md` はすでにケバブケースなので改名の候補にならない）。どれも実装ではなくテストのデータを直した
- 改善案: なし（検索がリンク先に当たるのは、子で使ってノイズになるかを利用ログの 0 件・件数で見る）
