# 2026-11-12 スライドの一覧の View とパターンの追加

## 訂正

- 起きたこと: スライドの一覧の View を pkm-html に足す案（ADR-0120 の最初の案）を出したところ、ユーザーから「pkm-slide って今はないの？ないなら既存の slide 機能はどうやってるんだ？プラグイン作って」と言われた。スライドは CLI（`.kit/bin/slide.mjs`）と pkm-html の「Open slide in browser」だけで扱っていて、使う人から見ると「slide プラグイン」があるように見えていた
- 改善案: 新しい機能の置き場所を決めるときは、使う人が機能をどの名前で呼んでいるか（「slide プラグイン」）を先に確かめる。プロダクトの文書（`surfaces/slide.md`）に、どの部品（CLI・pkm-html・pkm-slide）が何を受け持つかを書いた（直した）

## 食い違い

- 起きたこと: スライドの角丸に px のトークン（`--vt-radius-xl` = 28px）を使っていたため、一覧の縮小表示でカードが錠剤の形になっていた。design.md は「角丸はトークンを使う」としていたが、拡大縮小するキャンバスの中では合わない
- 改善案: design.md のスライドの節に、角丸は `--sl-radius`（u）を使うと書いた（直した）

## 移行

- 起きたこと: slide の CLI を変えると、子のすべての `index.html` が `slide.mjs check` で「古い」になる。ADR-0117 では取り込み後にビルドし直す手順がなかった
- 改善案: vault-upgrade に `slide.mjs build --all` の段を足した（直した。ADR-0120 の 3）
