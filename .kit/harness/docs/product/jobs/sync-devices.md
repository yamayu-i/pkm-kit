# 端末を持ち替えても、同じ Vault で続ける

- 端末: PC / スマホ
- 望む成果: [3](../strategy.md#望む成果)

## ジョブ

PC とスマホを行き来するとき、どこで書いたものも失わずに続きから使いたい。どの端末で作業しても安心できるように。

## 今の流れ

1. 書くだけでよい。画面を表示している間、戻ってきたとき、起動したときに自動で同期する（[PKM Git](../surfaces/git-sync.md)）。急ぐときは Git: Sync
2. 同期の区切りで、未コミットの変更が snapshot としてコミットされる。オフラインの間はコミットせず、つながったときに送る。コンフリクトしても止まらず、マーカーを残したまま同期する
3. 送れたかどうかは、ステータスバーの Git: Synced / Not synced で分かる
4. 残しておきたい版は Keep this version で名前を付けて残す
5. コンフリクトは後で解く（コマンド「List unresolved conflicts」）

## 関わる概念

[同期と snapshot](../concepts/sync-snapshot.md)

## うまくいっている兆し

- 端末ごとの snapshot のコミットが続いている
- ステータスバーが Git: Synced に戻る。同期の記録（Show sync log）に error が増えない
- コンフリクトのマーカーが長く残らない

## 知られている困りごと

まだない。
