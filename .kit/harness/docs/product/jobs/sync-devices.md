# 端末を持ち替えても、同じ Vault で続ける

- 端末: PC / スマホ
- 望む成果: [3](../strategy.md#望む成果)

## ジョブ

PC とスマホを行き来するとき、どこで書いたものも失わずに続きから使いたい。どの端末で作業しても安心できるように。

## 今の流れ

1. 書き始める前に pull、書き終えたら push する（コマンドかリボン。[PKM Git](../surfaces/git-sync.md)）
2. 未コミットの変更は自動でコミット（snapshot）される。コンフリクトしても止まらず、マーカーを残したまま同期する
3. リモートが先に進んでいたら、push の前に知らせる
4. コンフリクトは後で PC で解く（コマンド「List unresolved conflicts」）

## 関わる概念

[同期と snapshot](../concepts/sync-snapshot.md)

## うまくいっている兆し

- 端末ごとの snapshot のコミットが続いている
- コンフリクトのマーカーが長く残らない

## 知られている困りごと

まだない。
