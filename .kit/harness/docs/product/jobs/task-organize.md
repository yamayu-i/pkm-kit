# スキマ時間に Inbox と Someday を片付ける

- 端末: スマホ / PC
- 望む成果: [2](../strategy.md#望む成果)

## ジョブ

数分の空き時間ができたとき、溜まった Inbox と、見直す時期の来た Someday を 1 件ずつ片付けたい。溜めたものが重荷にならず、やるべきものだけが予定に入るように。

## 今の流れ

1. [Organize](../surfaces/task-organize.md) を開く。Inbox の古い順 → revisit を過ぎた Someday → 見ていない期間が長い Someday の順に 1 件ずつカードが出る
2. スワイプ・ボタン・矢印キーで決める: Do Date（カレンダーで選ぶ。Inbox からなら estimated も）、Someday へ、あとで、Cancel、もう終わっていた
3. 1 つ前に戻せる

## 関わる概念

[Inbox](../concepts/task-inbox.md)、[Someday](../concepts/task-someday.md)、[Do Date](../concepts/task-do-date.md)、[estimated](../concepts/task-estimate.md)

## うまくいっている兆し

- Inbox の件数が増え続けない
- Organize がスマホで使われている
