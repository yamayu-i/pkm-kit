# 朝、今日やることを決める

- 端末: PC / スマホ / AI 経由
- 望む成果: [1](../strategy.md#望む成果)

## ジョブ

一日を始めるとき、期限を落としていないかと昨日の残りを確かめて、今日やることを決めたい。迷わずに作業に入れるように。

## 今の流れ

1. リボンの「Daily を開く」（[リボン](../surfaces/ribbon.md)）か、左サイドバーの Daily（[Tasks サイドバー](../surfaces/task-sidebar.md)）を押す。Daily は一覧ペインに開く（[一覧ペインとノートペイン](../surfaces/layout-panes.md)）
2. [Daily](../surfaces/task-daily.md) の段階を順に片付ける: 期限切れ → 前回のボード → 期限が近い → ボード。今日が Do Date の issue と今日の routine は、自動でボードに載っている
3. [task board](../surfaces/task-board.md) で、カードをグループ（午前・午後など）に置く。前に置いたグループに初めから出る
4. AI と相談するときは、task-coach が MCP で状況を読み、負荷（見積もりの合計と使える時間）を見て、載せすぎを減らす（[MCP と task-coach](../surfaces/task-mcp.md)）

## うまくいっている兆し

- Daily を開いた日の多くで、その日のボードが締まっている
- 期限切れの段階に残る件数が増え続けない
- 同じ issue の持ち越しが繰り返されない
