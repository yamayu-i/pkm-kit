# 場面（jobs）

使う人が pkm-kit を使う場面。1 場面 = 1 ファイル（[育て方の規則](../README.md#育て方の規則)）。場面はプラグインをまたぐので、領域は接頭辞と下の見出しで表し、フォルダで分けない。

## 書式

```markdown
# <場面の名前>

- 端末: PC / タブレット / スマホ / AI 経由
- 望む成果: [戦略](../strategy.md#望む成果) の番号

## ジョブ

<状況> とき、<したいこと>。<期待する結果> できるように。

## 今の流れ

1. 手順（通る面へのリンク）

## 関わる概念

## うまくいっている兆し

観測できる行動（記録や git の履歴から分かるもの）で書く。

## 知られている困りごと

機会の Issue（ラベル `ux`）へのリンク。なければ「まだない」。
```
