# 一日の終わりに締める

- 端末: PC / スマホ / AI 経由
- 望む成果: [1](../strategy.md#望む成果)

## ジョブ

一日を終えるとき、残ったものの行き先を決めて、今日の記録を残したい。明日の朝に昨日の後片付けから始めずに済むように。

## 今の流れ

1. [Today](../surfaces/task-today.md) の [task board](../surfaces/task-board.md) で、未完了のカードを片付ける: Close、Cancel、Do Tomorrow、Move Do Date、Inbox。routine はその日のうちに closed か canceled にする
2. 未完了が 0 になったら締める。デイリーノートの `## Task board` 節に、完了・持ち越し・worklog の要約がリンク付きで書かれる
3. 締め忘れたボードは、次に Today を開いたとき「Previous boards」に出る
4. AI と振り返るときは、task-coach が持ち越しを片付けてボードを締め、振り返りをデイリーノートの末尾に追記する（[MCP と task-coach](../surfaces/task-mcp.md)）

## 関わる概念

[task board](../concepts/task-board.md)、[routine](../concepts/task-routine.md)、[Do Date](../concepts/task-do-date.md)、[Inbox](../concepts/task-inbox.md)、[デイリーノート](../concepts/note-daily.md)

## うまくいっている兆し

- ボードがその日のうちに締まる（翌日の「Previous boards」で締める割合が低い）
- Do Tomorrow で持ち越した issue が、翌日に片付く
