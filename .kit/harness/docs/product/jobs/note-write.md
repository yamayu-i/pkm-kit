# ノートを書き始める

- 端末: PC / スマホ
- 望む成果: [2](../strategy.md#望む成果)

## ジョブ

書きたいことが浮かんだとき、置き場所や書式を考えずに書き始めたい。後で探せて、wiki にも取り込める形で残るように。

## 今の流れ

1. その日のことなら、リボンの「今日のデイリーノートを開く」（[リボン](../surfaces/ribbon.md)）。なければテンプレートから作られる
2. それ以外は、[テンプレートから作成](../surfaces/template-create.md)（コマンドかリボン）。テンプレートを選ぶと、置き場所とファイル名が決まる
3. 開いたノートの上には [ノートのヘッダー](../surfaces/template-header.md) が出る
4. 図を描くときは、コマンド「図を作る」で Draw.io を開く。保存すると `asset/` に図ができ、カーソルの位置に参照が入る（[Draw.io の図](../surfaces/drawio.md)）
