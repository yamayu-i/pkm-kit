# 思いついたことを、すぐ置く

- 端末: PC / スマホ
- 望む成果: [2](../strategy.md#望む成果)

## ジョブ

作業中や移動中に、やることを思いついたとき、考えを止めずにその場で置いておきたい。忘れる心配をせずに、今していることに戻れるように。

## 今の流れ

1. リボンの「issue をまとめて作成」か、[Tasks サイドバー](../surfaces/task-sidebar.md) のボタン、またはコマンドで [まとめて作成](../surfaces/task-capture.md) を開く
2. 1 行 1 件で書く。箇条書きを貼ってもよい。Mod+Enter（スマホはボタン）で作る
3. 作った issue は Inbox に入る。priority や日付はここでは決めない
4. 1 件だけなら [Inbox](../surfaces/task-inbox.md) の上の入力欄からも作れる

## 関わる概念

[issue](../concepts/task-issue.md)、[Inbox](../concepts/task-inbox.md)

## うまくいっている兆し

- スマホから作られる issue がある
- Inbox に入った issue が、時間をおかずに整理される（[スキマ時間の整理](task-organize.md)）

## 知られている困りごと

まだない。
