# label

## 目的

やることを分類し、色で見分けて絞り込めるようにする。

## 状態

issue と routine の `label`（名前のリスト）。色と並び順は `issue/labels.json`。Obsidian の tags とは別。

## 操作

issue 画面や一覧で付ける。Labels で追加・改名・色・並べ替え・削除。

## 使い方の筋道

改名すると、付いている issue と routine の label も書き換わる。使われている label は消せない。文字が読めない色は保存できない。
