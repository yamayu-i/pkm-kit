# Inbox

## 目的

まだ何も決めていないやることを 1 か所に集め、後でまとめて決められるようにする。

## 状態

保存しない。open で、Do Date・soft deadline・deadline のどれもない issue を Inbox と見なす。

## 操作

まとめて作成か Inbox の入力欄で入れる。Organize で 1 件ずつ決める。どの画面の「Inbox に戻す」でも、日付を消して戻せる。

## 使い方の筋道

作った issue は Inbox に入る。Do Date か期限を入れると Inbox から出る。
