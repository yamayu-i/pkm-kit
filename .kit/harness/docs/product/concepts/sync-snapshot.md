# 同期と snapshot

## 目的

PC とスマホで同じ Vault を使い、どこで書いたものも失わない。Git の CLI を開かなくてよい。

## 状態

Vault は git のリポジトリ。各端末の PKM Git が、同期のたびに未コミットの変更を snapshot としてコミットし、main に送る。共有の状態は、共有済み（Synced）、共有待ち（Not synced）、オフライン、接続を確認、同期できない（Sync failed）のどれか。

## 操作

自動の同期（前景の一定の間隔、戻ってきたとき、起動）、Sync now、Keep this version、Show sync log、未解決のコンフリクトを一覧（コマンド・リボン・ステータスバー）。

## 使い方の筋道

書くだけでよい。同期の区切りで snapshot を取り、取り込んでから送る。オフラインの間はコミットせず、つながったときにまとめて 1 つにする。残しておきたい版は Keep this version で名前を付けてコミットする。保存のたびの細かな版はファイル回復にある。両方の端末で同じ行を変えると、マーカーを入れたまま同期し、止まらない。後で解く。マーカーを入れられないファイルはリモート側を採り、手元の版を別名で残す。片方が消し、片方が編集したときは編集側を残し、その記録を全端末に届ける。一覧で残すか消すかを選ぶまで、件数に出続ける。同期できないときは、内容を失わずに次の同期でやり直し、記録（Show sync log）に残す。
