# デイリーノート

## 目的

その日のことを書く 1 枚のノート。ボードを締めた記録もここに残る。

## 状態

`daily/YYYY/MM/YYYY-MM-DD.md`（`type: daily`）。タイトルはファイル名の日付。本文にすでに書かれた内容は、仕組みも AI も変えない（追記だけ）。

## 操作

今日のデイリーノートを開く（なければテンプレートから作る）。Daily notes の一覧で見る。

## 使い方の筋道

ボードを締めると `## Task board` 節に要約が入る。AI は振り返りを末尾に追記し、wiki への反映先のリンクを末尾に足す。タスクの View の「Daily」とは別のもの。
