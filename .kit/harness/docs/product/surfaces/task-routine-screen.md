# routine 画面

- 種類: 画面（`routine/r-N.md` を開いたときのヘッダー）
- 開き方: [Routines](task-routines.md) の行、ボードのカード
- 場面: [朝の計画](../jobs/task-plan-day.md)

## 今の振る舞い

1. created と更新日時
2. ID と summary（押して編集）、active のスイッチ
3. くり返し、start、end
4. group、priority、label
5. 直近 14 日の結果（closed / canceled / 未記録 / 予定なし）。読み取りだけ
6. estimated / total / average
7. worklog、本文

status、Do Date、期限、親子は持たない。
