# テンプレートから作成

- 種類: コマンド（モーダル）
- 開き方: コマンド「Create new file from template」（リボンのボタンはない）。ホットキー（Cmd + N など）は Obsidian で割り当てる
- 場面: [ノートを書き始める](../jobs/note-write.md)

## 今の振る舞い

- 1 つのモーダルで、テンプレートを選び、ファイル名（ID で決まるテンプレートではタイトル）と、テンプレートの追加の入力を入れる。作られるパスがその場で見える
- テンプレートを切り替えると、置き場所・ファイル名・追加の入力欄が切り替わる
- 同じパスにノートがあればエラーを出し、上書きしない
- ノートのエディタ（編集モード）でカーソルが出ているときは、「Create and link」（Cmd/Ctrl + Opt/Alt + Enter）でノートを作り、開かずに、カーソル位置にリンク（表示は `title`、なければ `name`、なければファイル名）を入れる
- 作ったノートを [ノートペイン](layout-panes.md) で開き、決めた位置（なければ末尾）にカーソルを置く

## 入力と制約

選んだテンプレートと title、保存先、prompt の値からパスを解決します。同名ファイルがある場合や不正なパスでは作成できません。

## 操作と保存

テンプレートを展開した新しいノートを作ります。既存のノートを上書きしません。prompt-date があれば保存の前に日付を聞き、キャンセルなら作りません。

## 失敗時と戻し方

テンプレートがない場合は template/ と上流の既定・設定を確認します。重複なら title や保存先を変えます。エラーの通知が出たらファイル一覧で作成結果を確認します。

## 端末の違い

PC は Mod+Enter やホットキーを利用できます。スマホでも画面の作成ボタンを使えます。テンプレートの改訂や任意の保存先の準備は PC で行います。
