# テンプレートから作成

- 種類: コマンド（モーダル）
- 開き方: コマンド「テンプレートから新規ファイルを作成」、リボン。ホットキー（Cmd + N など）は Obsidian で割り当てる
- 場面: [ノートを書き始める](../jobs/note-write.md)

## 今の振る舞い

- 1 つのモーダルで、テンプレートを選び、ファイル名（ID で決まるテンプレートではタイトル）と、テンプレートの追加の入力を入れる。作られるパスがその場で見える
- テンプレートを切り替えると、置き場所・ファイル名・追加の入力欄が切り替わる
- 同じパスにノートがあればエラーを出し、上書きしない
- 作ったノートを [ノートペイン](layout-panes.md) で開き、決めた位置（なければ末尾）にカーソルを置く
