# HTML の表示

- 種類: View
- 開き方: ファイルエクスプローラー、Markdown リンク、クイックスイッチャーから `.html` / `.htm` を開く。書き出しは、コマンド「Export HTML to tmp/」か、ファイルのメニュー
- 場面: まだない（ユーザー体験の定義を子の Vault で読む場面は Issue #42 で足す）

## 今の振る舞い

- Vault の中の HTML を、ノートペインのタブに読み取り専用で出す。編集の手段はない。ファイルが変わると出し直す
- HTML の中のスクリプトは動かない。外部の画像・CSS・フォントは読み込まない（その部分は欠ける）
- Vault の中の画像（HTML からの相対パスか、Vault ルートからのパス）は出る。1 枚 10MB まで。Vault の外を指すものは出ない
- リンクを押すと、Vault の中のファイルはこのタブで Obsidian で開き、`https:` / `mailto:` は OS のブラウザ（メール）で開く。`#見出し` はその位置までスクロールする。それ以外（`javascript:`、`file:` など）は何もしない。見つからないファイルは通知で知らせる
- ライト / ダークは Obsidian のテーマに合わせる。トークン（`var(--vt-…)`）で書いた HTML はデザインルールの色と大きさになる。トークンを使わない HTML は、その HTML の色のまま出る

## tmp/ への書き出し

- 開いている HTML（コマンド）か、右クリックした HTML（ファイルのメニュー）を、それだけで開ける 1 ファイルにして `tmp/<名前>.html` に書き出す。同じ名前があれば `<名前> 2.html` のように別名にする（上書きしない）。書き出したパスを通知で知らせる
- 書き出した HTML は、ブラウザで開くとトークンの値で表示され、ライト / ダークは OS の設定に合わせる。Vault の中の画像と図（編集用 XML を除いたもの）が入る。スクリプトと外部の読み込みは入らない
- PC の Claude Code は `node .kit/bin/html.mjs export <ファイル>` で同じことをする

## 使う概念

なし（ノートではない。frontmatter も type も持たない）
