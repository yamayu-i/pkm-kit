# HTML の表示

- 種類: View
- 開き方: ファイルエクスプローラー、Markdown リンク、クイックスイッチャーから `.html` / `.htm` を開く。書き出しは、コマンド「Export HTML to tmp/」か、ファイルのメニュー。スライドをブラウザで開くのは、コマンド「Open slide in browser」、ファイルのメニューの「Open in browser」、タブの右上のボタン
- 場面: [体験定義と仕様を確認する](../jobs/guide-read.md)

## 今の振る舞い

- Vault の中の HTML を、ノートペインのタブに読み取り専用で出す。編集の手段はない。ファイルが変わると出し直す
- HTML の中のスクリプトは動かない。外部の画像・CSS・フォントは読み込まない（その部分は欠ける）
- Vault の中の画像（HTML からの相対パスか、Vault ルートからのパス）は出る。1 枚 10MB まで。Vault の外を指すものは出ない
- リンクを押すと、Vault の中のファイルはこのタブで Obsidian で開き、`https:` / `mailto:` は OS のブラウザ（メール）で開く。`#見出し` はその位置までスクロールする。それ以外（`javascript:`、`file:` など）は何もしない。見つからないファイルは通知で知らせる
- ライト / ダークは Obsidian のテーマに合わせる。トークン（`var(--vt-…)`）で書いた HTML はデザインルールの色と大きさになる。トークンを使わない HTML は、その HTML の色のまま出る

## スライドをブラウザで開く

- [スライド](slide.md)（`slide/` の下のデッキの `index.html`）は、この View ではスクリプトが動かないので、全スライドが縦に並んだ一覧として出る（Slide Show・レビューは使えない）
- スライドを開いている間は、タブの右上に「Open in browser」のボタンが出る。押すと OS の既定のブラウザで開く。コマンド「Open slide in browser」と、ファイルのメニューの「Open in browser」も同じ。スライド以外の HTML には出ない
- ブラウザで開けない端末では、通知で知らせる

## tmp/ への書き出し

- 開いている HTML（コマンド）か、右クリックした HTML（ファイルのメニュー）を、それだけで開ける 1 ファイルにして `tmp/<名前>.html` に書き出す。同じ名前があれば `<名前> 2.html` のように別名にする（上書きしない）。書き出したパスを通知で知らせる
- 書き出した HTML は、ブラウザで開くとトークンの値で表示され、ライト / ダークは OS の設定に合わせる。Vault の中の画像と図（編集用 XML を除いたもの）が入る。スクリプトと外部の読み込みは入らない
- PC の Claude Code は `node .kit/bin/html.mjs export <ファイル>` で同じことをする

## 使う概念

なし（ノートではない。frontmatter も type も持たない）

## 入力と制約

HTML は読み取り専用です。スクリプトと外部の資源を使いません。Vault 内の画像は 1 枚 10MB まで。

## 操作と保存

表示時に HTML を安全な iframe に入れ、テーマと画像を補います。Export HTML to tmp/ は共有用の別ファイルを作り、同名なら番号を足して元を上書きしません。

## 失敗時と戻し方

外部の CSS やスクリプトで描く内容は欠けます。画像が出ない場合は相対パスと上限を確認します。隠しフォルダ内の HTML はファイル一覧から開けないため、定義書の入口は pkm-guide/ に置きます。

## 端末の違い

PC とスマホのどちらでも閲覧と書き出しができます。スライドの動く機能はブラウザを使い、開けない端末では通知を確認します。
