# Tasks Now

- 種類: ダイアログ
- 開き方: リボンの Tasks Now、コマンド「Tasks Now」
- 場面: [作業しながら残す](../jobs/task-work.md)

## 今の振る舞い

現在の日時、PKM State（最後に整理してからの時間、worklog が止まっている時間、連続して記録している時間）、記録中のタスク群、今日の残りのタスクを表示します。値がない場合は経過時間を断定せず「–」を出します。

- Running の Pause は群を再開するために保持し、Stop は群を破棄します。
- Paused の Resume は保持した群を再開し、Discard は保持だけを捨てます。
- 各行の再生／停止はそのタスクだけに作用します。
- Space は一時停止／再開、Shift+Space は停止／保持した群の破棄です。入力欄では発動しません。
- 操作中は群の操作を無効にし、失敗は通知で知らせます。

## 入力と制約

経過時間は保存済みの整理・worklog と現在時刻から計算します。まだ記録がない項目は値なしの表示になります。

## 操作と保存

Pause は群のログを止めて、この端末の設定に再開対象を残します。Stop はログを止めて群を破棄します。Resume は保持した群の記録を新しく開始し、Discard は群だけを捨てます。

## 失敗時と戻し方

保存中は群の操作を重ねられません。失敗は通知で知らせます。Pause 前までの worklog は残り、止めた時間帯を再開時に遡って記録しません。

## 端末の違い

PC とスマホで同じダイアログを使います。一時停止した群は端末ごとの設定で、端末間の共有を前提にしません。
