# Labels

- 種類: View
- 開き方: [Tasks サイドバー](task-sidebar.md)、コマンド

## 今の振る舞い

- 行: 色（ピッカーと `#rrggbb`）、名前、プレビューのバッジ、使っている件数、上へ / 下へ / 削除
- 追加・改名・色・並べ替え・削除。下書きを「保存」でまとめて書く。未保存のときはバナーと「元に戻す」
- 名前が空・重複、色の形式が違う・文字が読めない色（4.5:1 未満）はエラーで、保存できない
- 使われている label は消せない（理由をツールチップに出す）。改名すると issue と routine の label も書き換わる

## 使う概念

[label](../concepts/task-label.md)

## 根拠

[ADR-0024](../../../../src/docs/adr/0024-label-manager.md)

## 入力と制約

名前と色を持ちます。同じラベルを issue・routine・member で共用します。

## 操作と保存

ラベルの設定を保存し、各ノートの label がその名前を参照します。色は表示上の識別で、status や priority を変更しません。

## 失敗時と戻し方

対象を探せない場合はラベルの表記と絞り込みを確認します。ラベルを変えるときは、同じ名前を参照するノートへの影響も確認します。

## 端末の違い

PC とスマホで同じ管理画面を使い、色だけに意味を任せず名前も表示します。
