# Labels

- 種類: View
- 開き方: [Tasks サイドバー](task-sidebar.md)、コマンド

## 今の振る舞い

- 行: 色（ピッカーと `#rrggbb`）、名前、プレビューのバッジ、使っている件数、上へ / 下へ / 削除
- 追加・改名・色・並べ替え・削除。下書きを「保存」でまとめて書く。未保存のときはバナーと「元に戻す」
- 名前が空・重複、色の形式が違う・文字が読めない色（4.5:1 未満）はエラーで、保存できない
- 使われている label は消せない（理由をツールチップに出す）。改名すると issue と routine の label も書き換わる
