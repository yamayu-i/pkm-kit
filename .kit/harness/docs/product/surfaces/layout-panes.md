# 一覧ペインとノートペイン

- 種類: 画面の配置（vault-task と vault-template の両方）
- 場面: [朝の計画](../jobs/task-plan-day.md)、[前に書いたノートを探す](../jobs/note-find.md)

## 今の振る舞い

- PC とタブレット: 一覧の View（Daily、Issues など、Daily notes など）は、メイン領域の左の「一覧ペイン」にタブで開いて固定する。一覧ペインがなければ、最後に使ったタブを左右に分けて左に開く
- 一覧ペインがあるとき、プラグインから開くノート（一覧の行、ボード、サイドバー、issue 画面のリンク、作ったノート、今日のデイリーノート）は右の「ノートペイン」に開く。Ctrl/Cmd+クリックでノートペインに新しいタブ
- スマホ: 画面を分けず、一覧の View を固定したタブで開く。ノートは別のタブで開き、一覧のタブは置き換わらない
