# Board groups

- 種類: View
- 開き方: [Tasks サイドバー](task-sidebar.md)、コマンド
- 場面: [朝の計画](../jobs/task-plan-day.md)

## 今の振る舞い

- グループとサブグループ（2 階層まで）を、その場の入力欄で作る・名前を変える・並べる。上にボードでの並び方の小さな見本
- 名前の検査（空・`/`・同じ階層での重複）を入力欄の下に出し、エラーがあるあいだは保存できない。下書きを「保存」でまとめて書く
- 名前を変えても、過去のボードのカードは移らない（未分類に出る）と画面に書いてある
