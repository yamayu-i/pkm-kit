## 目視レビュー

- **認証情報**: 扱わない: 問題なし
- **通信**: 新しく、固定の外部 URL `https://embed.diagrams.net/` を編集画面の iframe で読む（ADR-0064 で決めた例外。`requestUrl` は使わない）。編集を開いたときだけ、その図の編集用 XML を iframe（Draw.io の JavaScript）に `postMessage` で渡す。表示・コピー・書き出しは通信しない。送り先は固定の origin で、受け取るのは `event.origin` と `event.source` が合うものだけ。メッセージは JSON の形と大きさ（約 21 MiB まで）を確かめ、知らない event は捨てる: 問題なし（図の内容が Draw.io のページに渡ることは ADR と surfaces に書いた）
- **iframe**: `sandbox="allow-scripts allow-same-origin allow-forms"`（popup・トップの遷移・ダウンロードなし）。Vault の中の HTML は読まない（srcdoc を使わない）。pkm-html の iframe は変えていない（`allow-scripts` なし）: 問題なし
- **ファイル書き込み**: 編集の保存先は親が持つパス（開いた図、または `asset/<検査した名前>.drawio.svg`）だけで、iframe からはパスを受け取らない。既にある図は `vault.process()` で、編集を始めたときの中身と同じときだけ書く。違えば別名・上書き・戻るを人が選ぶ。書き出しは `tmp/` に新しいファイルを作るだけで、既にあるものを上書きしない。CLI は既にある出力を上書きしない: 問題なし
- **入力の検査**: SVG は 10 MiB、編集用 XML は 20 MiB 文字まで。ルートの `<svg>` は DOCTYPE の内部サブセット（実体の宣言）を拒否。共有用の SVG はスクリプト・イベント属性・`javascript:`・`<iframe>` などで書き出しを止める: 問題なし
- **データ消失**: 保存に失敗したら編集画面を残し、未保存として扱う。pkm-git は両側で変わった図をリモート優先＋ローカル版を別名（`.drawio.svg` のまま）で残す（テストを足した）: 問題なし
- **UI**: HTML 文字列を DOM に入れていない（`createEl` と `setIcon`。preview のモックの `innerHTML` は `src/` の外でプラグインに入らない）: 問題なし
