## 目視レビュー

- **スクリプトを含む HTML を Vault に置くこと**: Obsidian の中では今までどおり動かない（pkm-html が取り除く）。動くのは、使う人が OS のブラウザで開いたときだけ。動くスクリプトは CLI に束ねた共通のもの 1 つで、`index.html` の CSP は `default-src 'none'`、`script-src` はそのスクリプトの sha256 だけ、`img-src 'self' data: blob:`、`form-action 'none'`、`base-uri 'none'`。`deck.html` に書かれた `<script>`・`on*` 属性・`javascript:`・`<meta http-equiv>`・`<link>`・`<iframe>` などは pkm-html の `stripDangerous` で取り除き、`<style>` と外部の読み込みはビルドのエラーにする。インラインの `style` は、数値のカスタムプロパティだけを正規表現で許す。テストで、CSP のハッシュ・取り除く処理・エラーを確かめる: 問題なし
- **手で書き換えた index.html**: `slide.mjs check`（`verify.mjs` と CI が呼ぶ）が、ビルドし直したものとバイト列で比べて止める。CSP のハッシュを書き換えてスクリプトを足しても、ここで見つかる: 問題なし
- **ブラウザ側のスクリプト（`src/runtime/`）**: 通信しない（`fetch`・`XMLHttpRequest`・`WebSocket` を使わない。CSP でも止まる）。DOM には `textContent` と `createElement` だけで入れ、HTML 文字列を入れない。`localStorage` / `sessionStorage` に置くのは、レビューのコメント・見たビルドとスライドのハッシュ・テーマ・レビュー中かどうかだけで、秘密情報を扱わない（Obsidian の外のページなので SecretStorage はない）。クリップボードには、使う人が「Copy review」を押したときだけ書く: 問題なし
- **発表者ビューの postMessage**: `file://` では窓ごとに別の origin になり、送り先を origin で絞れないので `*` で送る（`http(s)` で開いたときは自分の origin に絞る）。送るのはスライドとステップの番号とビルドの ID だけ。受ける側は、ビルドの ID が合い、番号が整数のものだけを使い、スライドの位置を変える以外のことをしない。security-scan の「送り先を * にした postMessage」は、変数で渡しているので検出しない。ここに記録して残す: 問題なし（残る危険は、別のページがスライドの位置を動かせること）
- **ファイルの読み書き（CLI）**: 読むのは Vault の `slide/` の下の `deck.html` と、デッキのフォルダの中の添付だけ（`..`・絶対パス・スキームを拒否し、シンボリックリンクでフォルダの外を指すものは「ない」とする）。書くのは `slide/<デッキ>/index.html`、`new` の `deck.html`（既にあれば書かない）、`tmp/` の書き出し（同じ名前があれば番号を付け、上書きしない）。`slide/` の外のフォルダを指定するとエラー: 問題なし
- **CLI の pdf**: PC の Chrome 系のブラウザを `spawnSync` で起動する（引数は配列で渡し、シェルを通さない）。場所は決まった候補か `CHROME_PATH`。開くのは、`check` を通った自分の `index.html` の `file://` だけ。root で動くときだけ `--no-sandbox` を付ける（コンテナのため）: 問題なし
- **pkm-html の「Open in browser」**: Obsidian の `openWithDefaultApp` で OS に渡す。開けるのは `isSlideDeck`（`slide/<…>/index.html`）に当たるパスだけで、ほかの HTML には出ない。スクリプトを取り除く View の守りは変えていない（`allow-scripts` なし、CSP 同じ。bundle のテストで確かめる）。Vault に置かれた悪い HTML を `slide/x/index.html` という名前にすれば、使う人がボタンを押したときにブラウザで開く。これは OS のファイルの操作で開くのと同じ危険で、同期で届いたものは `slide.mjs check` が CI で見つける: 問題なし（残課題に書く）
