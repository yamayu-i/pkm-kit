## 機械的チェック

- `pnpm security:scan`: 8/8 pass。vault-html を、ビルドの再現（`main.js`・`manifest.json`・`styles.css`）と require の許可リスト（`obsidian` だけ）に足した。「危険な API」に `srcdoc` への代入を足し、許可は `packages/vault-html/src/ui/frame.ts` だけにした
- `pnpm check`: 成功（vault-html 13、design 62、shared 12、vault-ribbon 3、vault-template 112、vault-task 268、vault-git 84 件）
- `pnpm --filter vault-html preview:ui`（Chromium）: 成功。悪い HTML（`<script>`、`on*` 属性、`javascript:`、外部の `<img>` / `<link>` / `@import` / フォント / 背景、`<meta refresh>`、`<base>`、`<form>`、`<iframe srcdoc>`、`<object>` / `<embed>`、SVG の `<script>` と `<animate>`、`<noscript>`）で、スクリプトが動かず、ネットワークに届く要求が 0 件、iframe が遷移しないことを確かめた。除去を通さず sandbox + CSP だけのものでも同じ結果。守りを外す（`allow-scripts` を足し、CSP を `default-src *` にする）と失敗することも確かめた（検査が空振りしていない）
- `node .claude/scripts/verify.mjs`: すべて成功（移行 0005 のテストを含む）

## 目視レビュー

### vault-html

- **sandbox**: `allow-same-origin` だけ。`allow-scripts`・`allow-popups`・`allow-forms`・`allow-top-navigation` を付けていない。ビルド済み `main.js` に `allow-scripts` が含まれないことをテストで確かめている。`allow-same-origin` は、親がクリックを受け取るためだけ: 問題なし
- **CSP**: `default-src 'none'; img-src data:; style-src 'unsafe-inline'; font-src data:; form-action 'none'`。`<head>` の最初に入れ、元の HTML の `<meta http-equiv>` は消してから入れる。`script-src` を許していない: 問題なし
- **通信**: プラグインは通信しない（`requestUrl` も使わない）。外部のリンクは `https:` / `http:` / `mailto:` だけを `URL` で解析してから `window.open` に渡す。`javascript:` / `file:` / `app:` / `obsidian:` などは何もしない: 問題なし
- **ファイル**: 読むだけ（`cachedRead`、`readBinary`）。書く経路はない。画像のパスは Vault の中に正規化し、`..` で外に出るものと、`\`・NUL を含むものは捨てる。読む前に `TFile` であることと大きさ（10MB）を確かめる: 問題なし
- **UI**: HTML 文字列を Obsidian の DOM には入れない（`srcdoc` だけ）。フォントの変数の値は `;{}<>` を含むものを捨ててから `<style>` に入れる: 問題なし
- **既知の制限**: 読み込みの途中（`load` の前）にリンクを押すと、iframe の中で遷移しうる（sandbox で上位の画面とポップアップは開けないが、iframe の中で外部のページを開く）。読み込みは一瞬で、利用者の操作が要るので、許容する
